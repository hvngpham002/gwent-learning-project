# Shared Bibliography

`references.bib` is the shared bibliography for manuscripts under
`docs/research/manuscripts/`.

Rules:

- Prefer one canonical citekey per paper.
- Keep citekeys aligned with annotation package names where possible.
- Add low-confidence leads only after triage marks them as verified
  enough for annotation or manuscript planning.
- Do not treat this file as proof that a paper has been read. Completed
  annotations under `docs/research/literature/ai/annotations/` are the
  source of truth for literature-grounded project claims.

The file starts with high-priority cFp1 triage leads and can grow as
annotations are completed.
