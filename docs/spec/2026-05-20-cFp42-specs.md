# cFp42 Specs: Round Resource Exhaustion Casebook

Date: 2026-05-20

## Summary

Create an evidence-first casebook for the cFp41.2 expanded
`round_resource_exhaustion` queue before any new behavior tuning. This is an
analysis/documentation phase. It must not change `legal-heuristic-v1` behavior,
engine rules, legal moves, benchmark suite shape, UI behavior, catalog data, deck
presets, ratings, search, training, or product difficulty.

## Context

cFp41.2 committed the expanded 400-record starter-matrix artifact and matching
failure-mining artifact. The generated tuning queue ranks
`round_resource_exhaustion` first with 148 findings:

- `round_one_overinvestment`: 51 findings
- `round_three_low_resource`: 97 findings

cFp36 already showed that resource-pressure tuning can regress benchmark
strength when the signal is treated too broadly. cFp42 must classify the signal
before recommending implementation.
