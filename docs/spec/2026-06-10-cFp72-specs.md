Date: 2026-06-10

## Summary

cFp71 proved that the current valid-root sampled-world path can execute one
representative concrete move for every root public action bucket in every valid
sampled world. Both current and robust suites completed every public
action/sample pair with zero failed or deferred pairs and zero public outcome
divergence roots.

cFp72 should add the next benchmark-only search-readiness layer: a
post-one-ply branching budget probe. For each cFp68/cFp69/cFp70/cFp71 eligible
root, it should replay the same cFp71 first-ply representative execution inside
cloned sampled worlds, then stop after the one-ply transaction and measure the
next public legal action surface. It should report scalar branching and budget
pressure metrics only.

This is still not search gameplay. cFp72 must not execute a second ply, roll
out to terminal states, rank actions, estimate values, estimate win
probability, choose moves for a policy, or expose a product AI.

## Why This Phase Exists

The project is moving up an evaluation ladder toward hidden-information search
without jumping straight to strength claims. The recent ladder is:

- cFp68: valid-root-only contract with explicit skipped-root accounting.
- cFp69: root public action scaffold.
- cFp70: sampled-world root action availability.
- cFp71: one-ply public action outcome skeleton.

cFp72 should answer the next mechanical question:

> After each sampled one-ply public action execution, how large is the next
> legal/public action surface?

This is a budget and branching question, not an action-quality question. A
future search probe needs to know whether the second layer is tiny, manageable,
or explosive before adding rollout/value machinery.

## Scope

Implement a benchmark-only artifact generator that:

1. reads committed cFp68 eligible/skipped contract artifacts;
2. reads committed cFp69 public-action scaffold artifacts;
3. reads committed cFp70 sampled-world action-availability artifacts;
4. reads committed cFp71 one-ply outcome skeleton artifacts;
5. re-runs the matching benchmark suite through the root observer;
6. regenerates cFp61-style hidden multiset samples in memory for each cFp68
   eligible root;
7. rebuilds sampled root states in memory using the cFp70 sampled-state helper
   path;
8. collapses sampled legal moves into cFp60/cFp69/cFp70 public action buckets;
9. selects the same style of deterministic representative concrete move per
   public action bucket used by cFp71;
10. executes that representative move once inside a cloned sampled state;
11. determines the next acting seat/system context from the post-command state;
12. computes the next legal move surface only;
13. collapses that next legal move surface into public action buckets;
14. aggregates scalar branching/budget metrics at the root level;
15. carries skipped roots forward with cFp68/cFp69/cFp70/cFp71 skip accounting;
    and
16. writes deterministic hidden-info-safe artifacts.

The implementation must not change game behavior, benchmark match records,
policy selection, UI behavior, product AI behavior, deck data, rules, legal
move generation, rating formulas, sampler behavior, or existing cFp68/cFp69
/cFp70/cFp71 artifacts.

## Post-One-Ply Branching Contract

For each cFp68 eligible root:

1. Re-observe the benchmark root and verify it matches cFp68/cFp69/cFp70/cFp71
   contract identity and public fingerprint.
2. Regenerate valid materialized hidden multiset samples in memory.
3. Rebuild one sampled root state per valid sample using the cFp70 sampled-state
   rebuild path.
4. Compute sampled legal moves for the root acting seat.
5. Collapse sampled legal moves into public action buckets.
6. For each cFp69/cFp70/cFp71 root public action bucket:
   - find sampled legal moves in the matching sampled bucket;
   - if no sampled move exists, count `sample_action_missing`;
   - otherwise pick one deterministic representative concrete move from that
     bucket for internal execution only;
   - convert that move to an engine command with `commandFromLegalMove`;
   - execute the command on the sampled cloned state with `executeCommand`;
   - discard command payloads and raw event payloads immediately after deriving
     public scalar metrics.
7. From the post-command state:
   - if phase is `game_end`, count a terminal post-one-ply surface with zero
     next legal moves;
   - otherwise determine the next actor using the same semantics as
     `getHeadlessActingSeat` or a benchmark-local helper with identical
     behavior:
     - pending prompt seat wins;
     - mulligan phase chooses the first incomplete mulligan seat;
     - playing phase uses `currentTurn`;
     - round_end uses the system resolver seat convention;
     - game_end has no actor;
   - compute `getLegalMoves` for that next actor when one exists;
   - collapse next legal moves through the existing public action abstraction;
   - record scalar counts and bucketed stats only.
8. Aggregate root-level metrics across all first-ply public action/sample pairs.

Do not execute any next legal move. Do not run policy selection. Do not mutate
the original benchmark root state. Do not advance benchmark RNG outside cloned
states. Do not serialize concrete sampled actions, command payloads,
post-command states, event payloads, or raw public bucket keys.

- `zero`: 0 next public actions.
- `tiny`: 1-2 next public actions.

- `large`: 11-16 next public actions.

- `deferred`: any deferred pair.

- first-ply public action kind;

- next public action count;

ids, source ids, command payloads, event payloads, score totals, score deltas,
