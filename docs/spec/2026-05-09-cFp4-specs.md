# cFp4 Specs - First Long PIMC Caution Annotation Batch

## Phase

Cluster F Phase 4: First Source Package And Page-Bounded Annotation
For Long PIMC Caution

## Goal

Create the source package and annotate the first page-bounded batch for
Long, Sturtevant, Buro, and Furtak, "Understanding the Success of
Perfect Information Monte Carlo Sampling in Game Tree Search." This
starts the annotation source of truth for the PIMC / determinization
caution paper, using the shared bibliography citekey
`long2010understanding`.

## Inputs

Read:

- `AGENTS.md`
- `docs/PROJECT_STATE.md`
- `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`
- `docs/research/literature/ai/results/2026-05-08/queue.md`
- `docs/research/bibliography/references.bib`
- `audit/reports/2026-05-09-cFp3.1-report.md`

## Scope

1. Verify the shared bibliography contains `long2010understanding`.
2. Record the bibliography-aligned citekey/status in the Cluster F
   queue without changing priority order.
3. Create
   `docs/research/literature/ai/source/long2010understanding/manifest.yaml`.
4. Normalize the existing local
   `docs/research/literature/ai/source/long2010understanding/long2010understanding.pdf`
   to ignored local `source.pdf`.
5. Read only PDF pp. 1-7 of the local source.
6. Create
   `docs/research/literature/ai/annotations/long2010understanding/long2010understanding.md`
   with frontmatter, required sections, and page-grounded notes for the
   first batch.
7. Keep the final `Relevance To Gwent AI`, `Risks For Adaptation`, and
   `AI-Roadmap Decision` sections pending until the user explicitly
   confirms finalization after the page-bounded batch.
8. Update `docs/PROJECT_STATE.md`.
9. Create `audit/reports/2026-05-09-cFp4-report.md`.

## Out Of Scope

- No AI implementation code.
- No engine, simulation, UI, catalog, deck-builder, Card Studio, route,
  package, CI, or generated-asset behavior changes.
- No CFR/MCCFR source package or annotation work.
- No final Cluster F search implementation decision.
- No broad synthesis across multiple papers.
- No committing local research PDF files.

## Reading Rules

- Follow the mandatory batch protocol in
  `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`.
- Stop after writing notes for PDF pp. 1-7.
- Do not start another source in this phase.
- Every factual paper claim in the annotation must include a page or
  section anchor.
- Project-specific inferences must be labeled `Project inference:`.
