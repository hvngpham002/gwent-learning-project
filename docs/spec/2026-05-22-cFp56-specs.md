## Required Classification

Classify every one of the 70 findings into exactly one top-level bucket and
zero or more secondary flags. Use only scalar evidence already present in each
public finding.

Apply the top-level buckets in this order.

### Bucket A: `telemetry_unavailable_or_other`

Use when:

- `roundOneGuardTelemetryAvailable !== true`

Interpretation: do not patch behavior from this row without better evidence.

### Bucket B: `no_suppressed_pass_selected_base_geometry_present`

Use when:

- `roundOneFirstSuppressedPassDecisionIndex === null`, and
- `roundOneFirstBaseGeometryDecisionIndex !== null`

Required sub-labels:

- `recommendation_absent` when `roundOneFirstRecommendedDecisionIndex === null`
- `recommendation_present_but_no_pass` when `roundOneFirstRecommendedDecisionIndex !== null`

Interpretation: selected play-card geometry was visible, but the public
artifact does not show a suppressed pass. This is the highest-priority bucket
for possible future debug/reproduction because it may indicate exception,
recommendation, or finalization mismatch.

### Bucket C: `late_guard_intervention`

Use when:

- `roundOneFirstSuppressedPassDecisionIndex !== null`

Required sub-labels:

- `selected_base_geometry_before_pass` when
  `roundOneFirstBaseGeometryToFirstSuppressedPassDecisionGap !== null`
- `board_floor_before_pass_without_base_geometry` when selected base geometry is
  absent but `roundOneFirstBoardFloorToFirstSuppressedPassDecisionGap !== null`
- `hand_cap_before_pass_without_base_geometry` when selected base geometry and
  board-floor gap are absent but `roundOneFirstHandCapToFirstSuppressedPassDecisionGap !== null`
- `suppressed_pass_without_selected_geometry` otherwise

Interpretation: the guard has a visible selected pass, but it happens after
substantial round-one spending. This bucket does not by itself justify threshold
widening because many rows lack selected play-card base geometry.

### Bucket D: `no_suppressed_pass_cumulative_continue_candidate`

Use when:

- no first suppressed pass exists,
- selected play-card base geometry is absent, and
- one of these is true:
  - `roundOneContinuePlayCardTraceCount >= 8`
  - `round1PlayCardCount >= 8`
  - `roundOnePlayCardCountAfterFirstBoardFloorBeforeFirstSuppressedPass > 0`
  - `roundOnePlayCardCountAfterFirstHandCapBeforeFirstSuppressedPass > 0`

Required sub-labels:

- `board_floor_never_reached` when `roundOneFirstBoardFloorDecisionIndex === null`
- `hand_cap_never_reached` when `roundOneFirstHandCapDecisionIndex === null`
- `split_geometry_never_combined` when both board-floor and hand-cap indexes
  exist but no selected play-card base geometry exists

Interpretation: possible cumulative-spend issue without a visible suppressed
pass. This bucket can support a future cumulative-budget spec only if it is
dominant and not better explained by secondary pressure flags.

### Bucket E: `no_suppressed_pass_geometry_absent_low_confidence`

Use when:

- no first suppressed pass exists,
- selected play-card base geometry is absent, and
- Bucket D did not apply

Required sub-labels:

- `board_floor_never_reached` when `roundOneFirstBoardFloorDecisionIndex === null`
- `hand_cap_never_reached` when `roundOneFirstHandCapDecisionIndex === null`
- `split_geometry_never_combined` when both board-floor and hand-cap indexes
  exist but no selected play-card base geometry exists

Interpretation: selected-play geometry is missing and cumulative-spend evidence
is not strong enough for a behavior rule.

## Required Secondary Flags

For every row, derive these secondary boolean flags. A row can have multiple
flags.

- `catch_up_pressure`: `roundOneCatchUpSingleMoveBeforeFirstSuppressedPassCount > 0`
- `selected_card_advantage_pressure`: `roundOneSelectedCardAdvantageBeforeFirstSuppressedPassCount > 0`
- `exception_sequence_pressure`: any exception-before count is positive
- `ahead_at_first_suppressed_pass`: first suppressed pass exists and
  `roundOneScoreDeltaAtFirstSuppressedPass > 0`
- `tied_at_first_suppressed_pass`: first suppressed pass exists and
  `roundOneScoreDeltaAtFirstSuppressedPass === 0`
- `behind_at_first_suppressed_pass`: first suppressed pass exists and
  `roundOneScoreDeltaAtFirstSuppressedPass < 0`
- `selected_base_geometry_seen`: `roundOneFirstBaseGeometryDecisionIndex !== null`
- `selected_base_geometry_missing`: `roundOneFirstBaseGeometryDecisionIndex === null`

Secondary flags are explanatory overlays, not top-level classifications.

## Decision Rules

The casebook must end with one explicit recommendation:

- Recommend a cFp57 behavior patch only if one actionable bucket is clearly
  dominant (at least 60% of the 70 findings), uses a public scalar rule, and
  does not require weakening existing card-advantage, catch-up, match-winning,
  opponent-passed, last-gem, or single-card-hand exceptions.
- Recommend a cFp57 reproduction/debug phase if a small high-priority bucket
  such as Bucket B exists and needs exact fixture replay before behavior.
- Recommend pausing v1 heuristic tuning and moving to ratings/search if most
  rows are late-guard, missing-geometry, or exception/catch-up-heavy with no
  narrow public behavior rule.

If recommending behavior, include the exact proposed public condition and all
preserved exceptions. If recommending debug, name the public finding IDs to
replay. If recommending pause, name the next non-v1-tuning work.
