# Cluster F Phase 78 Specs - Public Action Identity Compact Projection v0

Date: 2026-06-15

Base: `dev`

## Summary

cFp77 successfully added `public-action-identities-v0/cFp77` as the first
durable public-action identity artifact. It closed the cFp76
`action_feature_source_gap` by emitting:

- one action identity row per collapsed public-action bucket per cFp68 eligible
  root;
- one root summary row per cFp68 eligible root; and
- one skipped-root row per cFp68/cFp69 skipped root.

cFp77 is source-consistent and hidden-info safe, but its robust
`action-identities.jsonl` is still 54,892,627 bytes. That is below the 90 MB
hard stop, but above the 50 MB robust soft target. cFp77 therefore correctly
recommended cFp78 as a compaction phase before any further search-consumer
work.

cFp78 should implement a benchmark-only compact projection over cFp77:

```text
public-action-identities-compact-v0/cFp78
```

The compact projection must not re-observe benchmark roots, execute actions,
rebuild sampled states, materialize hidden worlds, or change AI behavior. It
should read cFp77 artifacts as immutable source data and write a smaller,
consumer-ready action identity table that remains losslessly joinable to
cFp77 root summaries for all fields future consumers need.

## Decision

Implement a compact action identity projection, not a casebook subset.

Rationale:

- cFp77's robust action identity table is only ~4.9 MB over the 50 MB target,
  so a projection is likely enough.
- A subset would reduce size but would stop representing every public action
  bucket. That would force cFp79/cFp80 consumers to reason about sampling
  coverage before they can join cFp76 root features.
- The next useful milestone is still a complete action-level feature table,
  not an interesting subset.

cFp78 should preserve complete coverage:

- current: 18,820 compact action rows expected;
- robust: 153,842 compact action rows expected;
- current skipped rows: 63 expected;
- robust skipped rows: 340 expected.

If the compact robust `action-identities-compact.jsonl` remains at or above
50 MB, stop and report the measured fields responsible for size. Do not fall
through into cFp79 consumer work.

## Scope

Build a new artifact family that:

1. reads cFp77 `manifest.json`, `summary.json`, `action-identities.jsonl`,
   `root-summaries.jsonl`, `skipped-roots.jsonl`, and `report.md`;

   compact artifacts;
3. emits one compact action identity row for every cFp77 action identity row;
4. emits one compact root-index row for every cFp77 root summary row;

   `action-identities-compact.jsonl`, `root-index.jsonl`,
   `skipped-roots.jsonl`, and `report.md`;
7. proves compact rows can be joined back to cFp77 root summaries via
   `rootRef`;
8. records SHA-256 references for all consumed cFp77 source files;

10. updates AI Lab metadata to cFp78 as compact public-action identity
    infrastructure, not search gameplay;
11. updates benchmark docs, policy docs, roadmap, `docs/PROJECT_STATE.md`;
12. creates the required cFp78 audit report; and
13. commits and pushes the implementation branch after checks pass.

## Compact Row Design

The compact action row should keep complete action identity coverage while
removing repeated and derivable fields. Recommended schema:

```ts
type PublicActionIdentityCompactRow = {
  schemaVersion: "public-action-identities-compact-v0-action-v1";
  rootRef: string;
  publicActionRef: string;
  publicActionKeyHash: string;
  kind: PublicActionKind;
  ordinal: number;
  moveCount: number;
  sourceClass: string;
  target?: string;
  strengthBucket?: string;
  optionIndexLabel?: string;
};
```

Where:

- `kind` is the cFp77 `publicActionKind`.
- `ordinal` is the cFp77 `publicActionOrdinal`.
- `target` is a compact string derived only from public target categories:
  - omit when `targetKind` and `targetSide` are absent/`none`;
  - otherwise use a safe enum-like join such as
    `<targetKind>|<targetSide>|<targetRow>`, omitting empty components;
  - never include raw move IDs, card IDs, source IDs, card names, or runtime
    instance prefixes.
- `collisionCountWithinBucket` is derivable from `moveCount - 1`; do not store
  it unless the implementation proves storing it is still needed and under the
  50 MB target.
- `actionPhase` and `actionRound` are derivable from `rootRef` through
  `root-index.jsonl`; do not store them in every action row.
- `actionFamily` and `bucketSizeClass` remain derivable and should not be
  stored per row.

The root index row should be smaller than cFp77 `root-summaries.jsonl` but
should keep enough fields for cFp79 joins and grouped diagnostics:

```ts
type PublicActionIdentityCompactRootIndexRow = {
  schemaVersion: "public-action-identities-compact-v0-root-index-v1";
  rootRef: string;
  suiteId: string;
  matchupId: string;
  seed: string;
  mirrorGroupId: string;
  mirrorIndex: number;
  step: number;
  decisionIndex: number;
  phase: string;
  round: number;
  seatId: string;
  policyId: string;
  faction: string;
  deckPresetId: string;
  rootPublicFingerprint: string;
  publicActionCount: number;
  legalMoveCount: number;
  publicActionCollisionCount: number;
  largestPublicActionBucketSize: number;
};
```

If this root index is still too large, it may be compacted further, but it must
remain a complete one-row-per-root join table.

## Required Source Consistency Checks

The cFp78 summary must include source consistency fields proving:

- cFp77 summary `identityReadinessStatus` is `identity_ready`;
- cFp77 summary `sourceConsistency.status` is `ready`;
- cFp77 action identity row count equals actual
  `action-identities.jsonl` row count;
- cFp77 root summary row count equals actual `root-summaries.jsonl` row count;
- cFp77 skipped root row count equals actual `skipped-roots.jsonl` row count;
- compact action row count equals cFp77 action identity row count;
- compact root-index row count equals cFp77 root summary row count;
- compact skipped-root row count equals cFp77 skipped-root row count;
- every compact action row's `rootRef` exists in compact root index;
- every compact root index row's `rootRef` exists in cFp77 root summaries;
- every compact action key `(rootRef, publicActionRef)` is unique;
- every cFp77 action key `(rootRef, publicActionRef)` appears exactly once in
  compact action rows;
- every compact action row preserves cFp77 `publicActionKeyHash`;
- every compact action row preserves cFp77 public action kind;
- every compact action row preserves cFp77 ordinal;
- every compact action row preserves cFp77 move count;
- source artifact reference count is nonzero and empty-hash count is 0.

If any source consistency check fails:

- write no misleading ready report;
- set readiness to `source_consistency_failed`;
- stop before claiming cFp78 is consumer-ready.
