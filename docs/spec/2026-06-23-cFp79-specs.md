# Cluster F Phase 79 Specs - Search Consumer Action Features v1

Date: 2026-06-23
Branch: `codex/cFp79-search-consumer-action-features-v1`
Base: `dev`

## Summary

cFp76 proved the root-level search-consumer feature surface could be built from
committed cFp68-cFp74 artifacts, but it stopped correctly at
`consumerReadinessStatus: action_feature_source_gap` because no durable
per-public-action identity artifact existed yet.

cFp77 added complete public-action identities, and cFp78 compacted them below
the robust 50 MB soft target:

- cFp78 current compact action rows: 18,820.
- cFp78 robust compact action rows: 153,842.
- cFp78 current root-index rows: 3,979.
- cFp78 robust root-index rows: 32,147.
- cFp78 robust `action-identities-compact.jsonl`: 46,860,776 bytes
  (~46.86 MB), below the 50 MB target.
- cFp78 recommendation: `JOIN`.

cFp79 should now implement a benchmark-only, read-only action feature join:

```text
search-consumer-action-features-v1/cFp79
```

This phase should join cFp76 root features to cFp78 compact action identities
through cFp78 `root-index.jsonl`, producing nonempty per-public-action feature
rows without rollout, value, ranking, best-action selection, or product AI
behavior.

## Decision

Create a new v1 artifact family instead of modifying cFp76:

- cFp76 remains the immutable v0 root-feature baseline that documents the
  original source gap.
- cFp79 consumes cFp76 and cFp78 as source artifacts and emits a new normalized
  action-feature bundle.
- Root-level features remain one row per root.
- Action-level features remain one row per public action.
- Action rows reference root rows through `rootRef`.

Do not duplicate the full cFp76 root-feature payload into every action row. The
robust cFp76 root-feature file is already ~79.68 MB; duplicating it across
153,842 action rows would explode artifact size and produce a less usable
consumer contract. The consumer should join:

```text
action-features.jsonl.rootRef -> root-features.jsonl.rootRef
```

## Scope

Build `search-consumer-action-features-v1/cFp79` as a benchmark-only artifact
family that:

1. reads committed cFp76 artifacts;
2. reads committed cFp78 artifacts;
3. validates cFp76 source consistency/readiness;
4. validates cFp78 source consistency/readiness;
5. joins cFp76 root features to cFp78 root-index rows by public root identity;
6. emits one normalized root-feature row per cFp76/cFp78 eligible root;
7. emits one action-feature row per cFp78 compact action identity row;
8. carries skipped-root rows forward with cFp79 schema/run metadata and
   preserved classifications;
9. writes deterministic hidden-info-safe artifacts for current and robust
   starter suites;
10. records SHA-256 references for all consumed source artifacts;
11. updates AI Lab metadata to cFp79 as search-consumer feature infrastructure,
    not search gameplay;
12. updates benchmark docs, policy docs, roadmap, `docs/PROJECT_STATE.md`;
13. creates the required cFp79 decision note and audit report; and
14. commits and pushes the implementation branch after checks pass.

## Join Contract

### Root Key

cFp76 root features do not contain `rootRef`. cFp79 must join cFp76 root
features to cFp78 root-index rows by the public root identity:

- `suiteId`
- `matchupId`
- `seed`
- `mirrorGroupId`
- `mirrorIndex`
- `step`
- `decisionIndex`
- `phase`
- `round`
- `seatId`
- `policyId`
- `faction`
- `deckPresetId`
- `rootPublicFingerprint`

The joined cFp79 root-feature row must include `rootRef` from cFp78.

### Action Join

cFp79 action-feature rows must be generated from cFp78
`action-identities-compact.jsonl`. Each action row must reference a cFp79
root-feature row through `rootRef`.

The expected row counts are:

- current root-feature rows: 3,979;
- current action-feature rows: 18,820;
- current skipped-root rows: 63;
- robust root-feature rows: 32,147;
- robust action-feature rows: 153,842;
- robust skipped-root rows: 340.

## Action Feature Row Schema

The cFp79 action-feature row should contain action-local features and a join
reference to the root feature row. It must not duplicate the full cFp76 root
feature payload.

Required fields:

```ts
type SearchConsumerActionFeaturesV1ActionFeatureRow = {
  schemaVersion: "search-consumer-action-features-v1-action-feature-v1";
  featureRunId: string;
  rootRef: string;
  publicActionRef: string;

  // cFp78 compact action identity.
  kind: string;
  ordinal: number;
  moveCount: number;
  sourceClass: string;
  target?: string;
  strengthBucket?: string;
  optionIndexLabel?: string;

  // Derived action-local features.
  moveCountBucket: "single" | "small_collision" | "large_collision";
  collisionCountWithinBucket: number;
  hasCollision: boolean;
  hasTarget: boolean;
  hasStrengthBucket: boolean;
  hasOptionIndexLabel: boolean;

  // Join/readiness.
  rootFeatureRef: string; // same value as rootRef; explicit for downstream clarity
  actionIdentityRef: string; // `${rootRef}::${publicActionRef}`
  sourceConsistencyStatus: "ready";
  consumerReadinessStatus: "features_ready";
};
```

Do not include:

- `publicActionKeyHash` unless needed for source consistency in `summary.json`;
- full cFp76 root-feature fields;
- raw move/card/source IDs;
- action values or rankings.

`publicActionKeyHash` may appear in summary-level consistency diagnostics or
internal maps, but it should not be required in every action-feature row. This
keeps `action-features.jsonl` below the 50 MB target.

## Skipped Root Row Schema

Forward cFp76/cFp78 skipped-root classifications into cFp79 skipped rows with
cFp79 schema/run metadata. Preserve:

- public root identity;
- skip reason;
- invalid reason;
- cFp67 classifications/provenance labels when present;
- skip stage;
- skip counter dimensions.

## Required Source Consistency Checks

`summary.json` must include a source consistency object proving:

- cFp76 `consumerReadinessStatus` is `action_feature_source_gap`;
- cFp76 `sourceConsistency.status` is `ready`;
- cFp78 `compactReadinessStatus` is `compact_ready`;
- cFp78 `sourceConsistency.status` is `ready`;
- cFp76 root-feature summary count equals actual cFp76 `root-features.jsonl`
  line count;
- cFp76 skipped-root summary count equals actual cFp76 `skipped-roots.jsonl`
  line count;
- cFp78 compact action summary count equals actual cFp78
  `action-identities-compact.jsonl` line count;
- cFp78 root-index summary count equals actual cFp78 `root-index.jsonl` line
  count;
- cFp78 skipped-root summary count equals actual cFp78 `skipped-roots.jsonl`
  line count;
- every cFp76 root feature joins exactly one cFp78 root-index row;
- every cFp78 root-index row joins exactly one cFp76 root feature;
- cFp79 root-feature row count equals cFp76 root-feature row count;
- cFp79 action-feature row count equals cFp78 compact action row count;
- cFp79 skipped-root row count equals cFp78 skipped-root row count and cFp76
  skipped-root row count;
- every cFp79 action-feature row references an existing cFp79 root feature;
- every cFp78 action identity key `(rootRef, publicActionRef)` appears exactly
  once in cFp79 action-feature rows;
- duplicate cFp79 root refs are 0;
- duplicate cFp79 action identity refs are 0;
- source artifact reference count is nonzero and empty-hash count is 0.

If any source consistency check fails:

- set `consumerReadinessStatus` to `source_consistency_failed`;
- write an explicit failure report if artifacts are written;
- do not claim `features_ready`;
- do not recommend cFp80 feature consumers or search probes.
