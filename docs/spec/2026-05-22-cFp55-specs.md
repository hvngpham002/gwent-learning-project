## Required Evidence Fields

Add these fields to `round_one_overinvestment` finding evidence. Every field must be scalar `number | boolean | null`; no strings are required.

Use `null` when an index/count is not meaningful because the triggering event never occurred. Use `0` for counts when telemetry is available and the count is zero. When telemetry is unavailable, keep existing unavailable fields and add the new fields as `null` for indexes/gaps/count-before-style values where appropriate.

### First-Event Indexes

- `roundOneFirstPlayCardDecisionIndex`
- `roundOneFirstBoardFloorDecisionIndex`
- `roundOneFirstHandCapDecisionIndex`
- `roundOneFirstBaseGeometryDecisionIndex` (existing; keep)
- `roundOneFirstRecommendedDecisionIndex` (existing; keep)
- `roundOneFirstSuppressedPassDecisionIndex`

Definitions:

- A play-card decision is a round-1 playing trace whose selected kind is `play_card`.
- Board floor is reached when `roundOneBoardAfterSelectedMove >= ROUND_ONE_OVERINVESTMENT_BOARD_AFTER_FLOOR`.
- Hand cap is reached when `estimatedHandCountAfterSelectedMove <= ROUND_ONE_OVERINVESTMENT_HAND_AFTER_CAP`.
- Base geometry is reached when both board floor and hand cap are true on the same selected `play_card` trace.
- Suppressed pass is a trace whose selected kind is `pass` and whose analysis has `roundOneOverinvestmentRecommended === true`.

### First-Suppressed-Pass Context

- `roundOnePlayCardCountBeforeFirstSuppressedPass`
- `roundOneBoardAfterSelectedMoveAtFirstSuppressedPass`
- `roundOneHandAfterSelectedMoveAtFirstSuppressedPass`
- `roundOneScoreDeltaAtFirstSuppressedPass`
- `roundOneFirstPlayToFirstSuppressedPassDecisionGap`
- `roundOneFirstBoardFloorToFirstSuppressedPassDecisionGap`
- `roundOneFirstHandCapToFirstSuppressedPassDecisionGap`
- `roundOneFirstBaseGeometryToFirstSuppressedPassDecisionGap`

Definitions:

- Counts before first suppressed pass include only traces with decision index lower than `roundOneFirstSuppressedPassDecisionIndex`.
- Board/hand/score-delta at first suppressed pass come from that pass trace's `roundInvestmentAnalysis`. They are public scalar diagnostics and must not inspect cards.
- Gap fields are `firstSuppressedPassIndex - firstEventIndex`, or `null` if either side is absent.

### Continue-Phase And Post-Geometry Spend Counts

- `roundOneContinuePlayCardTraceCount`
- `roundOneContinuePlayCardTraceCountBeforeFirstSuppressedPass`
- `roundOnePlayCardCountAfterFirstBaseGeometryBeforeFirstSuppressedPass`
- `roundOnePlayCardCountAfterFirstBoardFloorBeforeFirstSuppressedPass`
- `roundOnePlayCardCountAfterFirstHandCapBeforeFirstSuppressedPass`

Definitions:

- A continue play-card trace has selected kind `play_card` and `analysis.recommendation === "continue"`.
- "After first X before first suppressed pass" means decision index is greater than the first X index and lower than the first suppressed-pass index. If first suppressed pass is absent, count traces after first X through the end of round-one traces.

### Score-Delta Sequence Counts

- `roundOneScoreDeltaBehindBeforeFirstSuppressedPassCount`
- `roundOneScoreDeltaTiedBeforeFirstSuppressedPassCount`
- `roundOneScoreDeltaAheadBeforeFirstSuppressedPassCount`
- `roundOneScoreDeltaBehindAfterFirstSuppressedPassCount`
- `roundOneScoreDeltaTiedAfterFirstSuppressedPassCount`
- `roundOneScoreDeltaAheadAfterFirstSuppressedPassCount`

Definitions:

- Use `analysis.scoreDelta`.
- "Before" means decision index lower than the first suppressed-pass index.
- "After" means decision index greater than the first suppressed-pass index.
- If no first suppressed pass exists, all "before" counts cover all round-one traces and all "after" counts are `0`.

### Exception Sequence Counts Before First Suppressed Pass

- `roundOneExceptionCardAdvantageBeforeFirstSuppressedPassCount`
- `roundOneExceptionSingleMoveCatchUpBeforeFirstSuppressedPassCount`
- `roundOneExceptionNonPlayCardBeforeFirstSuppressedPassCount`
- `roundOneSelectedCardAdvantageBeforeFirstSuppressedPassCount`
- `roundOneCatchUpSingleMoveBeforeFirstSuppressedPassCount`

Definitions:

- Count only traces with decision index lower than first suppressed pass, or all round-one traces if no suppressed pass exists.
- Use the existing `roundOneOverinvestmentReason`, `selectedMoveIsCardAdvantage`, and `catchUpStatus` fields.

## Implementation Guidance

Extend `buildRoundOneGuardTelemetry(...)` in `src/game/benchmark/failureMining.ts`.

Recommended approach:

1. Filter and sort eligible traces by `decisionIndex` before aggregating.
2. First pass: identify first indexes and first suppressed-pass trace.
3. Second pass: compute aggregate counts, before/after counts, and gap fields.
4. Keep existing fields and meanings unchanged.
5. Add unavailable defaults to `ROUND_ONE_GUARD_TELEMETRY_UNAVAILABLE`.
6. Preserve deterministic artifact ordering.

Do not add raw trace arrays or per-decision arrays to `findings.jsonl`. This phase must remain scalar-only.

The failure-mining schema version can remain `benchmark-failure-mining-v1` because this is additive evidence within the existing artifact format. If you believe a schema bump is necessary, stop and explain before changing it.
