# cFp12 Specs - First Glicko Annotation Batch

## Phase

Cluster F Phase 12: First Source Package And Page-Bounded Annotation
For Glicko Ratings

## Goal

Create the source package and annotate the first page-bounded batch for
Mark E. Glickman, "The Glicko system," using the shared bibliography
citekey `glickman1995glicko`.

## Inputs

Read:

- `AGENTS.md`
- `docs/PROJECT_STATE.md`
- `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`
- `docs/research/literature/ai/results/2026-05-08/queue.md`
- `docs/research/bibliography/references.bib`
- `docs/research/literature/ai/source/glickman1995glicko/source.pdf`
- latest relevant Cluster F annotation reports already in the worktree

## Scope

1. Verify the shared bibliography contains `glickman1995glicko`.
2. Record the source-package and in-progress annotation status in the
   Cluster F queue without changing priority order, including the
   previous queue alias `glicko1995`.
3. Create
   `docs/research/literature/ai/source/glickman1995glicko/manifest.yaml`.
4. Verify the existing local ignored
   `docs/research/literature/ai/source/glickman1995glicko/source.pdf`.
5. Read only PDF pp. 1-6 of the local source. This is the full local
   source and remains within the ten-page batch limit.
6. Create
   `docs/research/literature/ai/annotations/glickman1995glicko/glickman1995glicko.md`
   with frontmatter, required sections, and page-grounded notes for the
   first batch.
7. Keep the final `Relevance To Gwent AI`, `Risks For Adaptation`, and
   `AI-Roadmap Decision` sections pending until the user explicitly
   confirms finalization after the full read.
8. Update `docs/PROJECT_STATE.md`.
9. Create `audit/reports/2026-05-09-cFp12-report.md`.

## Out Of Scope

- No AI implementation code.
- No engine, simulation, UI, catalog, deck-builder, Card Studio, route,
  package, CI, or generated-asset behavior changes.
- No final Cluster F evaluation-ladder, rating-system, or benchmark
  decision.
- No broad synthesis across multiple papers.
- No completing or finalizing `glickman1995glicko`.
- No completing, finalizing, or rewriting other annotations.
- No committing local research PDF files.

## Reading Rules

- Follow the mandatory batch protocol in
  `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`.
- Stop after writing notes for PDF pp. 1-6.
- Do not complete final decision sections without explicit
  finalization confirmation.
- Do not start another source in this phase.
- Every factual paper claim in the annotation must include a page or
  section anchor.
- Project-specific inferences must be labeled `Project inference:`.
