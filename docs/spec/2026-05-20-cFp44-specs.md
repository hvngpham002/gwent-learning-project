# cFp44 Specs: Post-cFp43 Failure-Mining Casebook

Date: 2026-05-20

## Summary

Create a post-cFp43 evidence casebook from the stable current and expanded
failure-mining artifacts. This is an analysis/documentation phase. It must not
change `legal-heuristic-v1` behavior, `legal-heuristic-v0` behavior, engine
rules, legal moves, UI behavior, catalog data, deck presets, benchmark suite
shape, ratings, search, training, or product difficulty.

cFp43 reduced the targeted `round_one_overinvestment` signal, but it also
showed a small benchmark-strength tradeoff. cFp44 should decide what, if
anything, deserves the next behavior spec instead of blindly following the
stale top queue label.

## Scope

In scope:

- Read the committed public current and expanded benchmark/failure-mining
  artifacts.
- Optionally read the ignored local post-cFp43 repeat-run summary if present.
- Produce a durable cFp44 casebook/decision note.
- Update AI Lab/product policy metadata to cFp44 so `/ai-lab` stays current.
- Update AI Lab metadata tests.
- Update the v1 policy notes, `PROJECT_STATE`, and audit report.

Out of scope:

- Any change to `legalHeuristicPolicyV1.ts`, `legalHeuristicPolicyV0.ts`, or
  policy selection behavior.
- Any change to engine rules, scoring, legal moves, command execution, prompts,
  UI behavior, catalog data, deck presets, benchmark suite definitions, failure
  mining classifiers, ratings, search, training, or product difficulty.
- Regenerating benchmark artifacts.
- Adding new benchmark profiles or seeds.
- H100/Slurm work.
- Treating broad `suspicious_pass` as directly actionable without a narrower
  public-artifact case classification.

## Required Work

### 1. Create The Casebook

Create:

```text
docs/research/literature/ai/decisions/2026-05-20-cfp44-post-cfp43-failure-mining-casebook.md
```

The casebook must include:

- source artifact paths and schema identifiers;
- hidden-info boundary statement;
- current-vs-expanded benchmark result table;
- cFp41.2/cFp42/cFp43 comparison table:
  - cFp41.2 expanded: 310 / 85 / 5, 964 findings;
  - cFp43 expanded: 305 / 90 / 5, 878 findings;
  - explain that cFp43 reduced the targeted signal but regressed W/L by 5 wins;
- post-cFp43 signal table for current and expanded artifacts:
  - `round_one_overinvestment`
  - `round_three_low_resource`
  - `weathered_row_play`
  - `medic_timing_risk`
  - `suspicious_pass`
  - relevant suppressed pass categories;
- representative deterministic case IDs for each remaining nonzero actionable
  signal:
  - remaining `round_one_overinvestment`;
  - `round_three_low_resource`;
  - `weathered_row_play`;
  - `medic_timing_risk`;
  - calibrated `remaining_suspicious_pass`;
- outcome/faction/matchup distribution for each signal where the artifact
  fields allow it;
- false-positive/noise assessment for each signal;
- explicit recommendation for the next phase:
  - behavior patch;
  - analysis-only follow-up;
  - benchmark/failure-mining classifier cleanup;
  - or pause v1 heuristic tuning and move toward ratings/search.

### 2. Do Not Trust The Queue Blindly

The committed `tuning-queue.md` still ranks `round_resource_exhaustion` first.
cFp44 must re-evaluate that recommendation after cFp43:

- separate remaining `round_one_overinvestment` from `round_three_low_resource`;
- state whether the remaining `round_one_overinvestment` cases are still
  loss-correlated enough to tune;
- state whether `round_three_low_resource` is still mostly watch/noise;
- state whether `weathered_row_low_tempo` is now a better next behavior target;
- state whether `medic_no_target_timing=7` in expanded is enough evidence for
  another Medic patch;
- state whether broad `suspicious_pass` needs a casebook/classifier pass before
  any behavior change.

## Acceptance Criteria

- cFp44 casebook exists at the required decision path.
- Casebook uses only public committed artifacts plus optional ignored local
  repeat-run summary as verification.
- Casebook explicitly accounts for the cFp43 tradeoff:
  - targeted expanded `round_one_overinvestment` reduced from 51 to 26;
  - expanded W/L moved from 310/85/5 to 305/90/5.
- Casebook gives a concrete next recommendation and does not simply repeat the
  stale broad `round_resource_exhaustion` queue wording.
- AI Lab/product policy metadata points at cFp44.
- No AI policy behavior, v0 behavior, engine rules, legal moves, UI behavior,
  catalog data, deck presets, benchmark suite shape, failure-mining classifier,
  ratings, search, training, or product difficulty changes occur.
- Report and `PROJECT_STATE` are updated.
