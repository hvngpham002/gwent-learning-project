# Implementation Spec: Cluster C, Phase 24 - Draw Opponent Discard Leader

## Intent

Implement the next focused Tranche 2 leader-rule member from
`docs/leader-ability-matrix.md`: `draw_opponent_discard` for
`nilfgaard.emhyr-var-emreis-the-relentless` (Emhyr var Emreis: The
Relentless).

The cCp18 conflict section C-2 is already settled by the product owner and recorded in
the living rules docs: **catalog wins**. The Relentless draws a card from the
opponent's discard pile. Do not implement the older deck-tutor wording.

This is a Pattern 4 companion to cCp22 `restore_discard_to_hand`, but the
candidate pile is the **opponent's** discard pile and the chosen card moves to
the acting seat's hand.

The settled rule contract is:

- active one-shot leader;
- `UseLeader` opens a single `choose_card` prompt;
- no legal move when the opponent discard pile has no eligible cards;
- any card kind physically in the opponent discard pile is eligible, including
  units, heroes, specials, weather, generated / side-deck-only cards, and
  off-owner cards;
- the chosen card moves from the opponent discard pile to the acting seat's
  hand;
- the chosen card's `controller` becomes the acting seat;
- the chosen card's immutable `owner` is preserved;
- drawing the chosen card does not resolve that card's abilities;
- opponent discard card identities are public, but AI-owned prompt options must
  still remain hidden from the human UI through the existing prompt-move gate.

Do not bundle `random_medic`, `discard_two_draw_one_from_deck`,
`draw_extra_card`, `look_three_cards`, `cancel_leader`, deck-builder work, Card
Studio work, product prompt redesign, AI strategy tuning, or broader prompt
infrastructure beyond what The Relentless needs.

## Rule Semantics For cCp24

### Eligible Opponent Discard Pile

The leader is legal when the acting seat's opponent has at least one eligible
card ID in:

```ts
state.seats[opponentOf(actingSeat)].discard
```

Eligible:

- any card kind physically in the opponent discard pile;
- units;
- heroes;
- specials;
- weather cards;
- generated / side-deck-only cards that physically reached discard;
- cards whose immutable `owner` differs from the opponent discard-seat because
  the card occupied that board side when discarded.

Not eligible / not touched:

- acting seat's own discard pile;
- either hand;
- either deck;
- either side deck;
- removed from game;
- board rows;
- row horn slots;
- weather zone;
- leader zone;
- stale discard entries whose card instance or catalog source is missing.

If the opponent discard pile has no eligible cards, `getLeaderMove` must emit
no `use_leader` move. A manual `UseLeader` command in that state must reject
without setting `leaderUsed`, opening a prompt, or mutating state.

### Destination Semantics

For the chosen prompt option:

- move the chosen card from `state.seats[opponentSeat].discard` to
  `state.seats[actingSeat].hand`;
- set its `zone` to `{ kind: "hand", seat: actingSeat }`;
- set its `controller` to `actingSeat`;
- leave `owner` unchanged.

This matters for off-owner cards. The effect targets the physical opponent
discard pile. If an acting-seat-owned Spy-like card is currently in the
opponent discard pile, The Relentless may choose it and move it back to the
acting hand; `owner` remains the acting seat and `controller` becomes the acting
seat. If an opponent-owned card is chosen, `owner` remains the opponent and
`controller` becomes the acting seat.

### Prompt And Turn Semantics

Successful `UseLeader` should open a prompt and stop there:

- clone state;
- emit `ability_triggered`;
- set `state.pendingPrompt` to a `choose_card` prompt owned by the acting seat;
- emit `prompt_opened`;
- leave `seat.leaderUsed === false`;
- emit no `leader_used`;
- move no cards;
- keep `currentTurn` on the acting seat while the prompt is pending;
- hand off the turn only after a legal `ChoosePromptOption` resolves.

Prompt options should preserve opponent discard order and use labels that make
the source pile clear, for example:

```text
Draw <card name> from opponent discard
```

Recommended option IDs:

```text
draw-opponent-discard:<cardId>
```

The existing `PendingPromptOption.target.row` remains optional. cCp24 options
omit `row`, like cCp22 restore prompts.

### Legal Move Shape

`getLeaderMove` should emit exactly one `use_leader` move when:

- phase / turn / pass / prompt / leader-used gates allow leader use;
- the leader ability is implemented;
- the opponent discard pile has at least one eligible card.

The move should use:

```ts
target: { kind: "none" }
metadata.targetRequirement: "future_prompt"
metadata.targetCount: eligible opponent discard count
metadata.targetLabel: "opponent discard"
```

Do not expose hidden deck order, deck instance IDs, hand identities, or any
non-public zone. Opponent discard identities are public.

### Prompt Legal Move Shape

`getPromptMoves` currently emits `choose_prompt_option` moves only for the
prompt-owning seat. Preserve that gate.

For `draw_opponent_discard` prompt options, the legal move target should point
at the physical opponent discard card, not the acting seat:

```ts
target: {
  kind: "card_instance",
  side: "opponent",
  seatId: opponentSeat,
  cardId
}
```

For cCp22 `restore_discard_to_hand`, keep the current own-discard target shape:

```ts
target: {
  kind: "card_instance",
  side: "own",
  seatId: actingSeat,
  cardId
}
```

If the current prompt target builder needs a small branch by `prompt.abilityId`,
add it there. Do not break Medic row-bearing targets.

### Prompt Resolution

Successful `ChoosePromptOption` should:

- validate the prompt belongs to the acting seat;
- validate the option ID exists;
- validate the chosen card is still physically in the opponent discard pile;
- reject stale / wrong-seat / wrong-zone options with `EngineRuleError` without
  consuming the leader;
- clone state;
- move the chosen card to the acting seat's hand;
- emit `card_moved.reason === "leader_draw_opponent_discard_to_hand"`;
- set the chosen card's `controller` to the acting seat;
- leave the chosen card's `owner` unchanged;
- emit `prompt_resolved`;
- clear `state.pendingPrompt`;
- emit `ability_resolved` with outcome `"drew_opponent_discard"`;
- set `seat.leaderUsed = true`;
- emit `leader_used`;
- hand off the turn through the existing helper.

Do not emit `card_played`; the card is drawn to hand, not played.

Do not resolve moved card abilities. A drawn Medic, Spy, Muster, Scorch,
Weather, Avenger, Summon, Berserker, or Hero should behave normally only if
played later.
