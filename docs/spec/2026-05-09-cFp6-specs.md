# cFp6 Specs - First Lanctot MCCFR Annotation Batch

## Phase

Cluster F Phase 6: First Source Package And Page-Bounded Annotation
For Lanctot MCCFR

## Goal

Create the source package and annotate the first page-bounded batch for
Lanctot, Waugh, Zinkevich, and Bowling, "Monte Carlo Sampling for
Regret Minimization in Extensive Games." This starts the annotation
source of truth for the MCCFR sampling paper, using the shared
bibliography citekey `lanctot2009monte`.

## Inputs

Read:

- `AGENTS.md`
- `docs/PROJECT_STATE.md`
- `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`

## Scope

1. Verify the shared bibliography contains `lanctot2009monte`.
2. Record the bibliography-aligned citekey/status in the Cluster F
   queue without changing priority order.
3. Create
   `docs/research/literature/ai/source/lanctot2009monte/manifest.yaml`.
4. Normalize the existing local
   `docs/research/literature/ai/source/lanctot2009monte/lanctot2009monte.pdf`
   to ignored local `source.pdf`.
5. Read only PDF pp. 1-9 of the local source.
6. Create
   `docs/research/literature/ai/annotations/lanctot2009monte/lanctot2009monte.md`
   with frontmatter, required sections, and page-grounded notes for the
   first batch.
7. Keep the final `Relevance To Gwent AI`, `Risks For Adaptation`, and
   `AI-Roadmap Decision` sections pending until the user explicitly
   confirms finalization after the page-bounded batch.
8. Update `docs/PROJECT_STATE.md`.
9. Create `audit/reports/2026-05-09-cFp6-report.md`.

## Out Of Scope

- No AI implementation code.
- No engine, simulation, UI, catalog, deck-builder, Card Studio, route,
  package, CI, or generated-asset behavior changes.
- No final Cluster F AI method decision.
- No broad synthesis across multiple papers.
- No completing or finalizing `zinkevich2007regret`.
- No completing or finalizing `long2010understanding`.
- No CFR+, Deep CFR, NFSP, invalid-action-masking, or evaluation-ladder
  source package work.
- No committing local research PDF files.

## Reading Rules

- Follow the mandatory batch protocol in
  `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`.
- Stop after writing notes for PDF pp. 1-9.
- Do not complete final decision sections without explicit
  finalization confirmation.
- Do not start another source in this phase.

  section anchor.
- Project-specific inferences must be labeled `Project inference:`.
