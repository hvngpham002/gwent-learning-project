# cFp17 Specs - First Brown Deep CFR Annotation Batch

## Phase

Cluster F Phase 17: First Source Package And Page-Bounded Annotation
For Deep Counterfactual Regret Minimization

## Goal

Create the source package and annotate the first page-bounded batch for
Noam Brown, Adam Lerer, Sam Gross, and Tuomas Sandholm, "Deep
Counterfactual Regret Minimization," using the shared bibliography
citekey `brown2019deepcfr`.

## Inputs

Read:

- `AGENTS.md`
- `docs/PROJECT_STATE.md`
- `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`
- `docs/research/literature/ai/results/2026-05-08/queue.md`

- `docs/research/literature/ai/source/brown2019deepcfr/source.pdf`
- latest relevant Cluster F annotation reports already in the worktree

## Scope

1. Verify the shared bibliography contains `brown2019deepcfr`.
2. Record the source-package and in-progress annotation status in the
   Cluster F queue without changing priority order.
3. Create
   `docs/research/literature/ai/source/brown2019deepcfr/manifest.yaml`.
4. Verify the ignored local
   `docs/research/literature/ai/source/brown2019deepcfr/source.pdf`.
5. Read only PDF pp. 1-10 of the local source.
6. Create
   `docs/research/literature/ai/annotations/brown2019deepcfr/brown2019deepcfr.md`
   with frontmatter, required sections, and page-grounded notes for the
   first batch.
7. Keep PDF pp. 11-19 unread until explicit user continuation.
8. Keep the final `Relevance To Gwent AI`, `Risks For Adaptation`, and
   `AI-Roadmap Decision` sections pending until the user explicitly
   confirms finalization after the full read.
9. Update `docs/PROJECT_STATE.md`.
10. Create `audit/reports/2026-05-09-cFp17-report.md`.

- No AI implementation code.
- No engine, simulation, UI, catalog, deck-builder, Card Studio, route,
  package, CI, or generated-asset behavior changes.
- No final Cluster F Deep CFR or neural equilibrium roadmap decision.
- No broad synthesis across multiple papers.
- No completing or finalizing `brown2019deepcfr`.
- No reading PDF pp. 11-19 in this phase.
- No completing, finalizing, or rewriting other annotations.
- No committing local research PDF files.
- No continuing or finalizing
  `heinrich2016deepreinforcementlearningselfplay` or
  `glickman1995glicko`.

  `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`.
