# cFp3 Specs - First Cowling Ensemble Determinization Annotation Batch

## Phase

Cluster F Phase 3: First Source Package And Page-Bounded Annotation
For Cowling Ensemble Determinization

## Goal

Create the source package and annotate only the first page batch for
Cowling, Ward, and Powley, "Ensemble Determinization in Monte Carlo
Tree Search for the Imperfect Information Card Game Magic: The
Gathering." This starts the annotation source of truth for the
CCG-specific ensemble determinization paper, using the shared
bibliography citekey `cowling2012ensemble`.

## Inputs

Read:

- `AGENTS.md`
- `docs/PROJECT_STATE.md`
- `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`
- `docs/research/literature/ai/results/2026-05-08/queue.md`
- `docs/research/bibliography/references.bib`

## Scope

1. Verify the shared bibliography contains `cowling2012ensemble`.
2. Record the bibliography-aligned citekey/status in the Cluster F
   queue without changing priority order.
3. Create
   `docs/research/literature/ai/source/cowling2012ensemble/manifest.yaml`.
4. Normalize the existing local
   `docs/research/literature/ai/source/cowling2012ensemble/cowling2012ensemble.pdf`
   to ignored local `source.pdf`.
5. Read only PDF pp. 1-10 of the local source.
6. Create
   `docs/research/literature/ai/annotations/cowling2012ensemble/cowling2012ensemble.md`
   with frontmatter, required sections, and page-grounded notes for the
   first batch.
7. Keep the final `Relevance To Gwent AI`, `Risks For Adaptation`, and
   `AI-Roadmap Decision` sections pending until the full paper is read.
8. Update `docs/PROJECT_STATE.md`.
9. Create `audit/reports/2026-05-08-cFp3-report.md`.

## Out Of Scope

- No AI implementation code.
- No engine, simulation, UI, catalog, deck-builder, Card Studio, route,
  package, CI, or generated-asset behavior changes.
- No reading past PDF page 10 in this phase.
- No final Cluster F AI method decision.
- No broad synthesis across multiple papers.
- No committing local research PDF files.

## Reading Rules

- Follow the mandatory batch protocol in
  `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`.
- Stop after writing notes for PDF pp. 1-10.
- Do not continue to PDF page 11 unless the user explicitly replies
  with a continuation instruction.
- Every factual paper claim in the annotation must include a page or
  section anchor.
- Project-specific inferences must be labeled `Project inference:`.
