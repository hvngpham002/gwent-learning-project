# cCp32.2 Specs - Scoia'tael Post-Mulligan Presentation Repair

## Summary

cCp32.1 correctly moved the Scoia'tael first-player choice from pre-game setup to a post-mulligan engine prompt, but the product presentation now suppresses the AI mulligan exit animation when the AI is the Scoia'tael chooser. In the reported playtest (`ep4-mp8l0sfv`), the AI policy trace selected `choose_mulligan` with `selectedCardCount: 0` (`keep_hand`), but no keep-hand wave animation played. The exported `commandEventSummaries` also showed misleading `card_moved` events under the AI mulligan command because diagnostic event slicing included pre-command setup events.

## Goals

1. Preserve cCp32.1 rules: Scoia'tael first-player choice remains post-mulligan, engine-owned, and disabled for Scoia'tael mirror matches.
2. Restore AI mulligan presentation for exact-one Scoia'tael matches:
   - 0-card AI mulligan shows the keep-hand wave.
   - 1-card AI mulligan shows one redrawn slot.
   - 2-card AI mulligan shows two redrawn slots.
3. Ensure the post-mulligan Scoia'tael prompt does not bypass or suppress the existing AI mulligan presentation.
4. Keep AI-owned Scoia'tael prompt resolution deterministic (`self`) after the mulligan presentation has completed.
5. Fix product diagnostic command/event summaries so command slices skip pre-command event-log prefixes such as `match_started`.

## Required Code Changes

### 1. Authentic match presentation

File: `src/components/gwent/AuthenticMatchScreen.tsx`

- Do not suppress `pendingMulliganExitAnimation` merely because a Scoia'tael first-player prompt has resolved.
- Allow `pendingMulliganExitAnimation` to become visible when either:
  - `match.phase === "playing"`, or
  - `match.phase === "mulligan"` and the pending prompt is `abilityId === "scoiatael_choose_first"` with `stage === "scoiatael_first_player_choice"`.
- Keep the existing render rule that shows `AuthenticMulliganScreen` whenever `visibleMulliganExitAnimation` exists.
- After the animation is confirmed/dismissed, the product may then render the Scoia'tael prompt if it is human-owned, or allow the AI controller to resolve it if AI-owned.
- Do not reintroduce the removed pre-game selector.

### 2. Product diagnostic command/event slicing

File: `src/components/gwent/matchDiagnostics.ts`

- Update `buildCommandEventSummaries(...)` so it starts slicing at:

```ts
const totalCommandEventCount = commandHistory.reduce((total, record) => total + record.eventCount, 0);
let cumulativeEventCount = Math.max(0, eventLog.length - totalCommandEventCount);
```

- This matches the component-side `eventSlicesByCommandSequence(...)` behavior and prevents startup events (`match_started`, deck instantiation, initial draw events, etc.) from shifting command summaries.
- Keep the export hidden-info safe: only event type names are exported.
