## Phase

Cluster F Phase 2.2: Final Page-Bounded Cowling Annotation Batch

## Goal

Complete the `cowling2012ismcts` annotation after explicit user
permission by reading the final PDF page batch, pp. 21-25, appending
page-grounded notes immediately, and completing the pending final
decision sections now that the full paper has been read.

## Inputs

Read:

- `AGENTS.md`
- `docs/PROJECT_STATE.md`
- `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`
- `docs/research/literature/ai/source/cowling2012ismcts/manifest.yaml`

## Scope

1. Confirm the existing annotation has `pages_read: "1-20"`.
2. Read only PDF pp. 21-25 of
   `docs/research/literature/ai/source/cowling2012ismcts/source.pdf`.
3. Append page-grounded notes for the pages just read.
4. Update the annotation frontmatter to `pages_read: "1-25"` and
   `status: "complete"`.
5. Complete `Relevance To Gwent AI`, `Risks For Adaptation`, and
   `AI-Roadmap Decision`.
6. Update `docs/PROJECT_STATE.md`.
7. Create `audit/reports/2026-05-08-cFp2.2-report.md`.

## Out Of Scope

- No AI implementation code.
- No engine, UI, AI policy, simulation, catalog, test, route, CI, or
  package changes.
- No new paper annotation beyond `cowling2012ismcts`.
- No source package creation for the next paper.
- No broad roadmap synthesis across multiple papers yet.

## Reading Rules

- Follow the mandatory batch protocol in
  `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`.
- Stop after writing notes for pp. 21-25 and completing the annotation.
- Do not start `cowling2012mtg`, `long2010pimc`, or another source in
  this phase.
- Every factual paper claim in the annotation must include a page or
  section anchor.
- Project-specific inferences must be labeled `Project inference:`.
