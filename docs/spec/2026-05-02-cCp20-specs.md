# Implementation Spec: Cluster C, Phase 20 - Double Spies Passive Leader

## Intent

Implement the next narrowly scoped leader-rule tranche: `double_spies` for
`monsters.eredin-breacc-glas-the-treacherous`.

The post-cCp18 product decision is authoritative: `double_spies` is a passive
for the entire game. It is not a one-shot active leader and it is not a
snapshot-at-fire-time effect. While Eredin Breacc Glas: The Treacherous is a
seat's leader, all non-hero Spy units on the battlefield have doubled effective
strength for the whole match, including Spy units played after setup and after
the first scoring tick.

cCp20 should implement only this passive scoring behavior and its accounting.
Do not bundle prompt leaders, discard leaders, Agile optimization, setup-time
draw, or cancel/reaction work into this phase.

## Rule Semantics For cCp20

### Double-Spies Policy

Create a pure scoring-policy helper, analogous to cCp15's
`getWeatherPolicyBySeat` and cCp19's `getRowHornPolicyBySeat`.

Recommended shape:

```ts
export type DoubleSpiesPolicyBySeat = Partial<Record<SeatId, boolean>>;

export function getDoubleSpiesPolicyBySeat(
  state: MatchState,
  catalogLeaders: readonly CatalogLeaderSource[],
): DoubleSpiesPolicyBySeat
```

Exact signatures may vary to fit local type patterns, but the helper must:

- derive from leader source identity, not faction;
- return `{ [seatId]: true }` only for seats whose leader ability is
  `double_spies`;
- return no policy for missing leaders, unrelated leader abilities, or leaders
  absent from the supplied catalog;
- be exported through the core public surface if the current wildcard export
  does not already expose it.

### Scoring Behavior

When any non-cancelled seat has an active `double_spies` policy:

- every battlefield card whose catalog source includes `spy` receives a ×2
  multiplier;
- the effect applies on both board sides and all rows;
- the effect applies to Spy units regardless of owner/controller;
- the effect applies to future Spy units as soon as they enter the
  battlefield;
- hero Spy cards, if introduced later, are not doubled because Hero immunity
  still applies;
- the effect does not stack with itself if both seats somehow have
  `double_spies`;
- `CardScoreEntry.modifiers` should include a distinct marker such as
  `"leader_double_spies"` when the multiplier applies;
- no event should be required for normal passive scoring, because the effect is
  derived from leader identity every scoring tick.

Add explicit fields to `CardScoreEntry` if useful for transparency, e.g.:

```ts
spyMultiplier: number;
afterSpyMultiplier: number;
```

Recommended modifier order:

1. Weather
2. Double-Spies leader multiplier
3. Tight Bond
4. Morale Boost
5. Horn / leader-horn

This means a weathered non-hero Spy becomes `1 × 2 = 2` before later
Tight Bond / Morale / Horn-style modifiers. If King Bran changes the weathered
strength, double-spies multiplies the King Bran-adjusted weather value. If a
Spy also receives a row-horn or physical Commander's Horn, the modifiers compose
through the existing scoring pipeline after the double-spies stage.

Any engine behavior that already calls `calculateScores` for effective strength
should inherit this passive. Do not add one-off strength calculations.

### Legal Moves And Commands

`double_spies` is passive:

- `getLeaderMove` must return no `use_leader` move for
  `monsters.eredin-breacc-glas-the-treacherous`;
- `executeCommand({ type: "UseLeader" ... })` must not gain an executable
  branch for `double_spies`;
- `leaderUsed` must remain `false`;
- no `leader_used` event should be emitted for this passive.

If the existing command path returns a structured unsupported-leader error for
manual `UseLeader` attempts, preserve that pattern and add a focused regression
test.

## Required Tests

- Missing leader catalog or unrelated leader ability returns no policy.
- A non-hero Spy on either board side is doubled.
- Spies are doubled regardless of owner/controller.
- Spies played or moved onto the board after initial scoring are doubled on the
  next scoring pass.
- Non-Spy units are unaffected.

  passive applies.
