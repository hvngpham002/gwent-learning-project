## Selection Contract

For every cFp80 compact action:

1. Resolve rootRefId with cFp80 dictionaries.
2. Group all actions by resolved root reference.
3. Classify every action using the shared cFp81 helper.
4. Select a root only if it has at least one action and every action is consumer_ready.
5. Emit all and only the cFp80 actions belonging to each selected root.
6. Aggregate every non-selected eligible root; do not silently drop it.
7. Forward every inherited cFp80 skipped-root row with cFp83 metadata only.

Use these exclusion reasons, in this precedence order if conditions overlap:

    high_collision_action
    high_branching_context
    over_budget_context
    mixed_non_ready_root
    empty_action_surface

Also retain an aggregate count for every observed non-ready action label. The precedence choice must not conceal overlap.
