# cFp2 Specs - First Cowling ISMCTS Annotation Batch

## Phase

Cluster F Phase 2: First Source Package And Page-Bounded Annotation

## Goal

Create the first AI literature source package and annotate only the
first page batch of Cowling, Powley, and Whitehouse, "Information Set
Monte Carlo Tree Search." This phase starts the annotation source of
truth, but does not make a final AI roadmap decision because the paper
will still be partially unread after pp. 1-10.

## Inputs

Read:

- `AGENTS.md`
- `docs/PROJECT_STATE.md`
- `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`
- `docs/research/literature/ai/results/2026-05-08/queue.md`
- `docs/research/literature/ai/results/2026-05-08/handoff.md`
- `docs/research/bibliography/references.bib`

## Scope

1. Verify the shared bibliography contains `cowling2012ismcts`.
2. Create `docs/research/literature/ai/source/cowling2012ismcts/manifest.yaml`.
3. Verify whether
   `docs/research/literature/ai/source/cowling2012ismcts/source.pdf`
   exists before reading.
4. Read only pages 1-10 of the local source.
5. Create
   `docs/research/literature/ai/annotations/cowling2012ismcts/cowling2012ismcts.md`
   with frontmatter, required sections, and page-grounded notes for the
   first batch.
6. Keep the final `Relevance To Gwent AI`, `Risks For Adaptation`, and
   `AI-Roadmap Decision` sections pending until the full paper is read.
7. Update `docs/PROJECT_STATE.md`.
8. Create `audit/reports/2026-05-08-cFp2-report.md`.

## Out Of Scope

- No AI implementation code.
- No engine, simulation, UI, catalog, deck-builder, Card Studio, route,
  package, CI, or generated-asset behavior changes.
- No reading past page 10 in this phase.
- No final Cluster F AI method decision.
- No claims from raw model sweep outputs unless independently verified
  from the paper pages read.
- No committing local research PDF files.

## Reading Rules

- Follow the mandatory batch protocol in
  `docs/research/literature/ai/ANNOTATION_WORKFLOW.md`.
- Stop after writing notes for pp. 1-10.
- Do not continue to page 11 unless the user explicitly replies with a
  continuation instruction.
- Every factual paper claim in the annotation must include a page or
  section anchor.
- Project-specific inferences must be labeled `Project inference:`.

## Required Checks

- `git diff --check`
- `npm run check:project-state -- --base HEAD~1`

## Reporting Directive

Create:

- `audit/reports/2026-05-08-cFp2-report.md`

The report must include files changed, behavior changed, checks run,
acceptance criteria status, deviations, risks/follow-ups, Project State
Update, and recommended next step.
