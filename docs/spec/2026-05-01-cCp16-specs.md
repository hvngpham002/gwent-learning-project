# Implementation Spec: Cluster C, Phase 16 - Foltest Row-Scorch Leaders

## Intent

Implement the two Northern Realms active leader abilities that destroy the opponent's strongest units on a specific row when that row's total Strength is 10 or more:

- `northern-realms.foltest-son-of-medell` / `scorch_range`;
- `northern-realms.foltest-the-steel-forged` / `scorch_siege`.

cCp11 already implemented row-scoped unit Scorch through `findUnitScorchRowTargets`. cCp15 then made that effective-strength path leader-aware by threading `catalogLeaders` through Scorch scoring. cCp16 should wrap the existing row-Scorch engine primitive as active once-per-game leader commands.

This is a pure-engine rules phase. Keep the implementation narrow: legal moves, command execution, metadata/manifest classification, focused tests, rules docs, project state, and report.

## User-Facing Rule Decision For This Phase

The two cCp16 leaders are active once-per-game leaders. Using one replaces the player's card play for that turn, consumes the leader, resolves row Scorch against the opponent's matching row, and then hands off the turn.

Required mappings:

- `scorch_range` (`Foltest: Son of Medell`) targets the opponent's **Ranged Combat** row.
- `scorch_siege` (`Foltest: The Steel-Forged`) targets the opponent's **Siege Combat** row.

Use the same row-Scorch semantics as cCp11 unit row Scorch:

- compute effective Strength with the full scoring pipeline, including Weather, King Bran, Tight Bond, Morale Boost, and Horn;
- inspect the opponent's matching row only;
- if the row total is at least 10, destroy all tied strongest non-hero units on that row;
- Heroes are immune and cannot be targets;
- destroyed row cards go to the discard pile for the board side they occupied;
- Avenger/summon discard-trigger handling must match existing row-Scorch destruction behavior.

### Legal-Move Policy

For cCp16, only expose a `use_leader` legal move when the leader can actually destroy at least one target now.

That means:

- if the opponent row total is below 10, emit no `use_leader` move;
- if the opponent row total is at least 10 but the row contains only Heroes or otherwise has no eligible non-hero unit target, emit no `use_leader` move;
- if the row has one or more tied strongest eligible non-hero units and row total is at least 10, emit exactly one no-target `use_leader` move for the leader.

Rationale: unlike Clear Weather's historical no-op behavior, these active leaders have no card placement or deck-search target. Presenting a once-per-game action that can only no-op is bad for the engine UI/AI contract. If future QA confirms official UI allowed wasting these leaders, handle that as a separate policy change.

### 4. Legal Move Generation

Extend `getLeaderMove` in `src/game/core/legalMoves.ts`.

Keep existing gates:

- phase must be `playing`;
- acting seat must be current turn;
- seat must not have passed;
- no pending prompt;
- leader must exist;
- leader must not already be used;
- ability metadata must be `implemented`.

Existing behavior must remain unchanged for:

- `clear_weather`;
- cCp14 weather-pulling leaders;
- cCp15 King Bran passive;
- remaining placeholder leaders.

Add row-Scorch leader behavior:

- If the leader ability is `scorch_range` or `scorch_siege`, compute score breakdown with `calculateScores({ state, catalogCards, catalogLeaders })`.
- Use `findUnitScorchRowTargets(breakdown, seatId, row)` where `row` is the mapped row.
- Emit exactly one `use_leader` move only when `result.outcome === "destroyed"` and `result.targets.length > 0`.
- Use `target: { kind: "none" }`.
- Add metadata useful for diagnostics/UI, for example:
  - `targetRequirement: "none"`;
  - `targetRow`;
  - `targetSeatId`;
  - `targetLabel`;
  - `targetCardIds`;
  - `rowTotal`;
  - `targetCount`.

Do not add a new legal target kind.

### 5. Command Execution

Extend `executeLeader` in `src/game/core/commands.ts`.

Required behavior for row-Scorch leaders:

1. Validate the command through the existing legal-move path (`assertLegal`) before mutating state.
2. Confirm the leader ability is `scorch_range` or `scorch_siege`.
3. Confirm command target is absent or `{ kind: "none" }`.
4. Clone state only after validation.
5. Compute score breakdown with `calculateScores({ state, catalogCards, catalogLeaders })` on the cloned state.
6. Use `findUnitScorchRowTargets(breakdown, seatId, mappedRow)`.
7. Destroy all returned targets:
   - move each target to `{ kind: "discard", seat: target.seatId }`;
   - use `card_moved.reason: "scorch_destroyed"` for destroyed row cards;
   - emit/resolve discard-trigger deferrals and Avenger replacements exactly like existing row Scorch destruction paths.
8. Emit clear events:
   - `ability_triggered` using the leader source ID, leader card instance ID, and leader ability ID;
   - `scorch_resolved` using the leader source ID, leader card instance ID, leader ability ID, target card IDs, and row result outcome;
   - `ability_resolved` with the row result outcome;
   - `leader_used`.
9. Mark `seat.leaderUsed = true`.
10. Handoff turn exactly as other active leader commands do.

Rejected paths must not consume the leader:

- wrong target kind;
- row total below threshold or no eligible targets (should already fail `assertLegal` because no legal move exists);
- wrong turn/wrong phase/passed seat/pending prompt/already-used leader through existing legal validation;
- placeholder or unsupported leader ability.

### 8. Rules Documentation

Update `docs/gwent-rules.md` near the Scorch or leader sections.

Document:

- `Foltest: Son of Medell` (`scorch_range`) is an active leader that destroys the opponent's strongest Ranged Combat non-hero unit(s) when the opponent Ranged row total is at least 10.
- `Foltest: The Steel-Forged` (`scorch_siege`) is an active leader that destroys the opponent's strongest Siege Combat non-hero unit(s) when the opponent Siege row total is at least 10.

## Acceptance Criteria

- `scorch_range` and `scorch_siege` leader metadata are `implemented`.
- `northern-realms.foltest-son-of-medell` and `northern-realms.foltest-the-steel-forged` are active executable leaders.
- King Bran remains implemented passive and does not move into `executableLeaderSourceIds`.
- Row-Scorch leader legal moves appear only when the opponent's matching row has row total at least 10 and at least one eligible non-hero target.
- Row-Scorch leader commands destroy all tied strongest eligible non-hero units on the mapped opponent row.
- Effective strength and threshold use the current scoring pipeline, including King Bran.
- Heroes are immune.
- Destroyed row cards use board-side discard placement.
- Avenger replacement handling matches existing Scorch destruction behavior.
- The leader is marked used only after successful execution.
- Turn handoff after leader use matches existing active leader behavior.
- Existing Clear Weather, weather-pulling, King Bran, unit row-Scorch, Special Scorch, and Clan Dimun Pirate behavior remains unchanged.
- Official-porting rule-gap classification no longer flags the two Foltest row-Scorch leaders.
- `docs/gwent-rules.md`, `docs/PROJECT_STATE.md`, and the cCp16 report are updated.
