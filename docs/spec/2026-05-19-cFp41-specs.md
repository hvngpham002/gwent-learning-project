# Cluster F Phase 41 - Expanded Automated Playtest Volume

## Purpose

Add a larger deterministic automated playtest suite for discovery before
the next `legal-heuristic-v1` behavior patch.

This phase is evaluation infrastructure only. It must not change AI policy
behavior, engine rules, legal moves, UI behavior, catalog data, deck
presets, ratings, search, training, or product difficulty.

## Background

cFp40 added a reusable long-run benchmark wrapper. cFp40.1 refreshed the
current 120-record baseline:

- v1 smoke: 10 win / 2 loss / 0 draw vs v0.
- v1 starter matrix: 104 win / 14 loss / 2 draw vs v0.
- failure mining: 296 findings.

Manual logs are no longer enough to pick the next policy patch. The
project needs a larger deterministic discovery profile that the user can
run outside the agent runtime.

## Required Work

1. Add a new benchmark suite:
   - id: `benchmark-v1-starter-matrix-expanded-v1`;
   - same five official starter decks as `benchmark-v1-starter-matrix-v1`;
   - same 20 matchup definitions and mirrored seat assignments;
   - 10 deterministic seeds;
   - expected record count: 400.
2. Add npm commands:
   - `benchmark:v1-starter-matrix-expanded`;
   - `benchmark:v1-failure-mining-expanded`.
3. Add cFp40 long-run profiles:
   - `v1-expanded`;
   - `v1-expanded-repeat`.
4. Update AI Lab static metadata so it points at the expanded discovery
   suite and lists the expanded profile as available.
5. Update benchmark docs and benchmark-results docs.
6. Update tests for suite shape and AI Lab metadata.
7. Update `docs/PROJECT_STATE.md`.
8. Create a phase report.

## Out Of Scope

- Do not run the full expanded suite inside the agent turn.
- Do not commit expanded artifacts in this phase.
- Do not change `legal-heuristic-v1` scoring, pass logic, mulligan logic,
  prompt choice, or diagnostics.
- Do not add new decks or change existing deck presets.
- Do not add H100/Slurm submission.
- Do not add ratings/search/training.

## Acceptance Criteria

- `getBenchmarkSuite("benchmark-v1-starter-matrix-expanded-v1")` resolves.
- The expanded suite has 10 seeds, 20 matchups, mirroring enabled, and 400
  expected records.
- `npm run benchmark:long -- --profile v1-expanded --dry-run` succeeds.
- `npm run benchmark:long -- --profile v1-expanded-repeat --dry-run` succeeds.
- AI Lab view model describes the expanded benchmark suite and stays
  hidden-info safe.
- Standard checks pass.

## User-Run Command

After merge, run:

```bash
npm run benchmark:long -- --profile v1-expanded
```

Then point Codex to the generated `.local/benchmark-runs/.../summary.md`
or `run.json`.
