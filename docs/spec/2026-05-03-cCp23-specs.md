# Implementation Spec: Cluster C, Phase 23 - Shuffle Discards Into Decks Leader

## Intent

Implement the next focused leader-rule tranche from
`docs/leader-ability-matrix.md`: `shuffle_discards_into_decks` for
`skellige.crach-an-craite` (Crach an Craite).

This is Pattern 10 from the cCp18 Leader Ability Matrix: an active one-shot
leader that recycles both discard piles into their respective decks and shuffles
the affected decks deterministically.

The settled local rule contract is:

- active one-shot leader;
- no prompt and no UI choice;
- legal only if at least one seat has at least one card in discard;
- when used, each non-empty discard pile is moved into that same seat's deck;
- a card moves to the deck belonging to the discard pile it currently occupies,
  not necessarily to its original owner;
- each affected deck is shuffled using the engine's seeded RNG;
- unaffected empty-discard seats are not shuffled, to avoid mutating hidden deck
  order for no card movement;
- removed-from-game, side deck, hand, board, weather, row horn, and leader zones
  are not touched.

Do not bundle `draw_opponent_discard`, `random_medic`,
`discard_two_draw_one_from_deck`, `draw_extra_card`, `look_three_cards`,
`cancel_leader`, deck-builder work, AI strategy tuning, product UI layout work,
or broader shuffle infrastructure beyond what Crach needs.

## Rule Semantics For cCp23

### Eligible Discard Piles

The leader is legal when at least one current match seat has at least one card
ID in `state.seats[seatId].discard`.

Eligible:

- `state.seats.seat_a.discard`;
- `state.seats.seat_b.discard`;
- any card kind physically in those discard arrays, including units, heroes,
  specials, weather cards, row horns that have become discard cards, generated
  cards, and cards whose `owner` differs from the discard-seat because the card
  occupied that board side when discarded.

Not eligible / not touched:

- hand;
- deck;
- side deck;
- removed from game;
- board rows;
- row horn slots;
- weather zone;
- leader zone;
- stale discard entries whose card instance is missing.

If both discard piles are empty, `getLeaderMove` must emit no `use_leader`
move. A manual `UseLeader` command in that state must reject without setting
`leaderUsed` or mutating state.

### Destination Semantics

For every card in a non-empty discard pile:

- move it from `state.seats[discardSeat].discard` to
  `state.seats[discardSeat].deck`;
- set its `zone` to `{ kind: "deck", seat: discardSeat }`;
- set its `controller` to `discardSeat`;
- leave `owner` unchanged.

This matters for Spies and other off-owner cards. The engine already sends row
discards to the side they occupied; cCp23 must preserve that zone model. Crach
recycles the discard pile into the deck of the seat that currently owns that
discard pile, not back to each card's immutable owner.

### Shuffle Semantics

After moving a non-empty discard pile into its deck, shuffle that affected
seat's full deck with the existing deterministic RNG path:

```ts
const rng = createSeededRngFromState(state.rng.seed, state.rng.state);
state.seats[seatId].deck = shuffleWithRng(state.seats[seatId].deck, rng);
state.rng.state = rng.getState();
```

Use one RNG instance for the whole command and process seats in stable order:

```ts
["seat_a", "seat_b"]
```

Only affected seats with non-empty discard piles should be shuffled and emit
`deck_shuffled`. If `seat_a` discard is empty and `seat_b` discard is non-empty,
do not shuffle `seat_a`'s hidden deck. This avoids hidden-order no-op mutation.

RNG state advances according to `shuffleWithRng` for the affected decks. A deck
with length `0` or `1` consumes no random values because `shuffleWithRng` has no
swap loop, but it should still be considered an affected deck if cards were
recycled into it and should still emit `deck_shuffled`.

### Legal Move Shape

`getLeaderMove` should emit exactly one `use_leader` move when:

- phase / turn / pass / prompt / leader-used gates allow leader use;
- the leader ability is implemented;
- at least one seat discard pile is non-empty.

The move should use:

```ts
target: { kind: "none" }
metadata.targetRequirement: "none"
metadata.targetCount: total recyclable card count across both discard piles
metadata.targetLabel: "discard piles"
```

Do not expose hidden deck order, deck instance IDs, or shuffled order in legal
move metadata.

### Command Transaction

Successful `UseLeader` should:

- reject any target other than absent / `{ kind: "none" }`;
- reject if both discard piles are empty;
- clone state;
- emit `ability_triggered` for Crach's leader card;
- move all cards from each non-empty discard pile to that same seat's deck,
  preserving discard order for the move event sequence;
- emit one `card_moved` event per moved card with new reason
  `"leader_shuffle_into_deck"`;
- shuffle each affected deck in stable seat order using the existing seeded RNG
  helper;
- emit one `deck_shuffled` event per affected seat with reason
  `"leader_shuffle_into_deck"`;
- emit `ability_resolved` with outcome `"shuffled_discards"`;
- set `seat.leaderUsed = true`;
- emit `leader_used`;
- hand off the turn through the existing handoff helper.

Do not emit `card_played`; recycled cards are moved to hidden decks, not played.

Do not resolve moved card abilities. A recycled Medic, Spy, Muster, Scorch,
Summon, Avenger, Berserker, Weather, or Hero should behave normally only if
drawn and played later.

Rejections must raise `EngineRuleError` and must not mutate the input state.
