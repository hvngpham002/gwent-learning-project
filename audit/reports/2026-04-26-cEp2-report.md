# Cluster E Phase 2 Report - Engine-Backed Authentic Match Table V1

## Summary

Implemented the first playable authentic match table behind
`/?engine=1&ui=authentic` while preserving the legacy default route and the
diagnostic engine shell. The cEp1 gallery harness remains available through
`/?engine=1&ui=authentic&view=harness`.

During review, the new match path exposed a pre-existing engine regression:
Medic-revived Spy cards were returning to the acting player's board instead of
the opponent board. That rule path was fixed and covered with a focused core
regression test. Scoring, legal move generation, round resolution, and AI policy
logic did not change.

## Behavior Changed

- `/?engine=1&ui=authentic` now starts and renders a real engine-backed
  Northern Realms vs Nilfgaard match using the URL seed.
- The authentic match supports human mulligan, playable hand card selection,
  legal target action buttons, clickable legal board-row targets, implemented
  leader actions, pass, round resolution, prompt options, game-end status, and
  AI actions via `legal-heuristic-v0`.
- `/?engine=1&ui=authentic&view=harness` renders the existing cEp1 card
  foundation harness.
- `/` remains the legacy Redux UI.
- `/?engine=1` remains the diagnostic `EngineGameManager`.
- Medic revive now follows `docs/gwent-rules.md` section 17.2/17.3 for Spy
  cards: a revived Spy goes to the opponent's matching row, remains controlled
  by the player who revived it, and draws up to two cards for that player.

## Hidden-Info Review

- The authentic product UI does not use `selectEngineDebugAiHandCards`.
- AI hand and deck render as counts/back metadata only.
- Public board, weather, and discard cards render through `AuthenticCard`.
- Activity summaries use a public card lookup; hidden AI card identities fall
  back to safe labels when the card is not public.
- Browser smoke checks visible page text for internal field names and generated
  runtime instance-id patterns.

## Handoff Details Implemented

- Top bar with seed, round, phase, actor, and current next action.
- Left rail with opponent/player score cards, leader status, pile pairs, and
  weather.
- Center six-row tactical board ordered opponent siege/ranged/close, divider,
  player close/ranged/siege.
- Human hand strip using authentic cards.
- Right rail with inspector, legal actions, prompt panel, round/game status, and
  battle log.
- Parchment panels, mono labels, tabular scores, small radii, restrained
  ink-red highlights, and responsive stacking.

## Deviations

- `/?engine=1&ui=authentic&view=harness` is the documented harness route. The
  match route is the default authentic view.
- Discard pile display shows only the top public discard card and count. Full
  discard browsing remains deferred to cEp3.
- The implementation touched engine ability resolution to fix the reported
  Medic/Spy regression. This was outside the original cEp2 non-goal, but it was
  required before committing the playable match path because the UI can now
  exercise that prompt.

## Risks / Follow-Ups

- The match table is V1 and still relies on action-panel buttons for row horn,
  weather, global, and card-instance targets.
- Prompt UI is generic; Medic and Decoy product modals remain deferred.
- The AI policy is still `legal-heuristic-v0`, useful for plumbing but not
  strategic play quality.
- Browser smoke confirms pass and the action surface, but does not force a full
  deterministic game-end walkthrough. Deeper round-end and game-end product
  overlays remain cEp3 work.

## Recommended Next Step

Proceed to cEp3: product match interactions, prompt presentations, discard
browser, round-end overlay, and animation hooks over the same engine command
path.
