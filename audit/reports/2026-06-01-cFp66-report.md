## Behavior Changed

No gameplay behavior changed. cFp66 adds benchmark-only sampler memory:

- memory is keyed per benchmark match and perspective seat;
- only currently public cards and prompt-revealed cards for that perspective are added to memory;
- later hidden-zone accounting inspects only already-tracked runtime card ids;
- known hidden public-transfer hand/deck cards reduce hidden draw requirements;
- main-deck-attributable transfers consume the main-deck prior;
- side-deck-only and off-prior transfers reduce hidden count requirements without consuming main-deck prior;
- all serialized fields are scalar counts, buckets, statuses, labels, and reason counts.

## Public-Transfer Memory Design Summary

The sampler maintains a `SamplerPublicTransferMemoryState` per suite/matchup/
seed/mirror/perspective seat. Before each root is materialized, it scans only
zones visible to that perspective: board rows, horns, discards, removed piles,
weather, the perspective hand, and prompt-revealed opponent hand ids for prompts
addressed to the perspective. Those visible opponent-owned card ids are tracked
internally with their public source id.

For subsequent roots, the update step checks only tracked ids in `cardsById`.
If a tracked opponent-owned card is now in opponent hand or deck and is not
currently public/prompt-revealed, it becomes a known hidden public-transfer card.
Never-seen opponent hand/deck card ids are not enumerated or inspected.

## Hidden Hand/Deck Identity Peeking

Avoided. The implementation uses opponent hand/deck arrays only for counts.
Known hidden identities come only from cards already recorded from public zones
or from prompt reveal ids addressed to the same perspective seat.
