## Behavior Changed

cFp78 adds a new benchmark-only, read-only compact projection
(`public-action-identities-compact-v0`) over committed cFp77 public-action
identity artifacts. It does not:

- Modify any existing cFp77 artifact directory.
- Re-observe benchmark roots.
- Execute candidate actions, rebuild sampled states, or materialize hidden
  worlds.
- Run rollout search, PIMC evaluation, or ISMCTS/MCTS.
- Compute action values, expected values, reward targets, win
  probabilities, payoff tables, or principal variations.
- Rank actions or select best/chosen actions.
- Change gameplay behavior, engine rules, legal moves, AI policy behavior,
  sampler behavior, deck/catalog data, benchmark suite definitions, or
  rating artifacts.
- Expose raw move IDs, card instance IDs, card source IDs, source IDs,
  card/leader names, deck order, sampled hands/decks, or hidden payloads.

The only metadata effect is the `productPolicies.ts` update, which points
`legal-heuristic-v1` at cFp78 as the latest read-only benchmark
infrastructure phase, without changing `legal-heuristic-v1` or
`legal-heuristic-v0` gameplay behavior.

## Risks And Follow-Ups

- The robust `action-identities-compact.jsonl` (46.86 MB) is below the 50 MB
  soft target, so cFp79 may proceed with consumer feature joins. The 46.86 MB
  size leaves limited headroom before the target; cFp79 should monitor if
  compact action artifact sizes grow with wider feature fields.
- Robust `root-index.jsonl` (23.92 MB) is comfortably below the 90 MB hard
  stop and will not be the bottleneck for cFp79 joins.

## Recommended Next Step

Per the cFp78 decision note and the `cFp79Recommendation: JOIN` result:
because cFp78 compact action rows are complete, source consistency is `ready`
for both suites, and the robust `action-identities-compact.jsonl` (46.86 MB)
is below the 50 MB target, cFp79 should join cFp76 root features to cFp78
compact action identities to populate `action-features.jsonl` with
per-public-action feature rows. cFp79 should not recommend rollout, value
estimation, action ranking, best-action selection, win probability, or
reward targets from cFp78 alone.
