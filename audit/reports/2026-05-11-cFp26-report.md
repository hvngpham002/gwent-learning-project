## Behavior Changed

1. **Catch-up threshold:** `legal-heuristic-v1` now uses a tie-aware minimum score to win round. Nilfgaard (vs non-Nilfgaard) needs only to tie; all other faction combinations need to exceed.
2. **Last-gem pass gate:** Nilfgaard on its last gem can now correctly treat a tied reachable score as sufficient (not pass as impossible).
3. **Double-Nilfgaard tie:** Both seats being Nilfgaard means tie = draw, so the old behavior (need to exceed) is preserved.
4. **Diagnostic reason text:** The reason string in v1 decision traces now matches the actual selected move. If the selected move is `pass`, the reason no longer claims "catch-up move".
5. **AI deck faction export:** Product diagnostic exports now include `aiDeckFaction` when the opponent deck preset is known, instead of always `null`.
