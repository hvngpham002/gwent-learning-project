# Cluster E Phase 6.1 Report - Mulligan Flow Stabilization Patch

## Summary

Implemented the cEp6.1 stabilization patch for the authentic mulligan flow. The patch keeps normal product behavior unchanged, keeps `legal-heuristic-v0` as the production AI policy, and hardens only the presentation/debug/control paths around cEp6 mulligan animation and setup return.

AI mulligan strategy remains deferred. Card Studio remains deferred to cEp7.

## Behavior Changed

- Added a per-match presentation run key for mulligan animation state so rematch or fresh setup starts cannot inherit stale human/AI mulligan animation keys from a previous run using the same setup and seed.
- Cleared the frozen AI base-hand cache on rematch/start restart. This fixes the stale hidden-hand slot risk when the same setup/seed is reused.
- Paused human animation timers, AI review timers, AI choosing timers, and AI command dispatch while the `Return to setup?` confirmation modal is open. If the user stays, the presentation can continue; if they leave, the adapter is cleared as before.
- Moved debug-only AI mulligan move selection into `chooseDebugAiMulliganMove`, which selects only legal `choose_mulligan` moves.
- Kept the existing debug route contract sufficient:
  - `debugAiMulliganCount=0` forces a legal zero-card keep.
  - `debugAiMulliganCount=1` forces one legal one-card redraw if one exists.
  - `debugAiMulliganCount=2` forces two sequential legal one-card redraws if legal moves permit.
- Did not add `debugAiMulliganIndexes`.
- Did not change button, card, modal, deck-builder, pre-game, or match-table styling.
- Did not expose AI hand card names/source IDs/instance IDs in the default non-debug mulligan presentation.
