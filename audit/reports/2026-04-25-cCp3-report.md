## Engine State Summary

`MatchState` stores all runtime cards once in `cardsById`. Every `CardInstance` carries `instanceId`, `sourceId`, `sourceKind`, `owner`, `controller`, and `zone`. Seat zones store IDs for `deck`, `hand`, `discard`, `sideDeck`, and `removedFromGame`; leaders are tracked by instance ID. Each seat has `close`, `ranged`, and `siege` rows with `units: CardInstanceId[]` and `horn: CardInstanceId | null`. Shared weather is represented as `weather.entries`. Seats also track faction, gem counters, passed flags, controller metadata, and leader source ID. RNG metadata records seed, algorithm, and current numeric state after setup.

## Setup Transaction Summary

`startMatch(config)` accepts a seed, two seat configs, catalog cards, catalog leaders, and catalog deck presets. It validates distinct seats and preset/faction alignment, instantiates leader/main-deck/side-deck entries into compact card instances, shuffles main decks with the seeded RNG, draws 10 cards per seat into hand, sets both gem counters to 2, sets phase to `mulligan`, and selects the first turn from the same RNG stream. Only `StartMatch` is implemented through `executeCommand`; later commands are defined but intentionally throw placeholder errors in this phase.

## Event Model Summary

- `match_started`: records match ID, seed, and seats.
- `deck_instantiated`: records preset, faction, leader instance, main deck count, and side deck count.
- `card_moved`: records instance movement for instantiation, shuffle, and initial draw.
- `initial_hand_drawn`: records the initial 10-card hand IDs per seat.
- `turn_set`: records deterministic initial turn selection.
- Placeholder event types exist for `card_played`, `ability_resolved`, `prompt_opened`, `round_ended`, and `game_ended`.
