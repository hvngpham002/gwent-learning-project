## Risks / Follow-Ups

- cFp52 confirms a selected-play contradiction but intentionally does not patch
  behavior. cFp53 should inspect the exact policy code path before choosing the
  smallest repair.
- Fixture B also shows a later suppressed overinvestment pass after the selected
  contradiction. The cFp53 repair should preserve valid suppressed-pass behavior
  while blocking selected plays that already carry the guard recommendation.
- Threshold widening and cumulative-spend tuning remain unsupported by cFp52.
  They should not be added unless a later spec proves they are necessary without
  recreating the cFp36 broad-resource-gate regression.
