## Artifact Evidence Changed

Existing `round_one_overinvestment` findings now include hidden-info-safe scalar
guard-state evidence: trace/play-card counts, board/hand geometry counts,
recommendation and suppressed-pass counts, first decision indices, score-delta
direction counts, reason/exception counts, selected card-advantage/no-future-unit
counts, catch-up counts, and round-investment recommendation counts.

source IDs, runtime card instance IDs, move IDs, action refs, hand/deck/discard
