## Behavior Changed

No gameplay behavior changed.

cFp59 adds opt-in benchmark-only profiler plumbing. The headless simulation
loop now accepts an optional observer called after legal moves are generated and
before policy selection. The benchmark runner can pass public suite/matchup/
seed/mirror context into that observer. The observer returns no command and
does not influence selected moves.

No `legal-heuristic-v1`, `legal-heuristic-v0`, or `legal-first-v0` behavior
changed. No engine rules, legal moves, command semantics, prompts, scoring,
benchmark suite definitions, benchmark match records, failure-mining
classifiers/artifacts, rating formulas/artifacts, UI gameplay, catalog/deck
data, browser benchmark execution, product difficulty, or product-selectable
search AI changed.

## Deviations

No scope deviations.

cFp59 intentionally does not serialize wall-clock timing in committed artifacts.
The CLI prints elapsed total runtime to stdout only; committed profiler JSON and
Markdown omit timing so repeated artifact hashes remain stable.

## Risks / Follow-Ups

- The robust `roots.jsonl` artifact is large because it records one public
  scalar/count row per profiled root across 1,000 matches.
- cFp60 still needs a named sampler contract and sampled-world validator before
  any `determinized-pimc-probe-v0` run can be interpreted safely.
- SO-ISMCTS should remain deferred until a public action abstraction and sampler
  behavior are proven on a simpler determinized probe.
