# cFp34 Report - Automated AI Evaluation And Failure Mining

## Summary

cFp34 adds deterministic, hidden-info-safe failure mining for
`benchmark-v1-starter-matrix-v1`. The new command
`npm run benchmark:v1-failure-mining` writes `manifest.json`, `summary.json`,
`findings.jsonl`, and `report.md` under the suite's
`failure-mining/latest/` artifact path.

The implementation collects richer headless v1 decision traces only when
explicitly requested and uses them in memory. The committed artifacts contain
public IDs, aggregate counts/rates, booleans, and bucket labels only.

## Hidden-Info Safety Review

The writer scans the combined generated artifacts for forbidden raw-debug and
private-zone tokens before writing succeeds. The committed artifact bundle does
not contain raw engine state, raw command logs, raw event logs, private hand/deck
arrays, unsafe debug result objects, runtime seat instance IDs, or hidden hand
card names.

Behavior-level findings use only safe trace fields: selected move kind,
aggregate hand-shape counts/buckets, pass booleans, round-investment enums,
weather strength buckets, and Medic timing buckets/booleans.

  round-three resource states.
