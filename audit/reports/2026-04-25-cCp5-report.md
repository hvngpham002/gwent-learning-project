## Command API Summary

`executeCommand(command)` still supports `StartMatch`. Stateful commands use:

```ts
executeCommand({ state, command, catalogCards, catalogLeaders })
```

The executor clones `MatchState` before mutation, validates commands against `getLegalMoves`, and returns `{ state, events }`. Illegal or unsupported commands throw `EngineRuleError` with a code and compact diagnostic details. Catalog records remain external to `MatchState`.

## Transaction Surface Covered

| Command | Supported? | Notes |
|---|---|---|
| `StartMatch` | Yes | Delegates to `startMatch`. |
| `ChooseMulligan` | Yes | Supports 0, 1, or 2 unique acting-hand cards through legal-move validation. |
| `PlayCard` unit/hero | Yes | Places on legal board row; Spy targets opponent side while retaining acting controller. |
| `PlayCard` Special Horn | Yes | Places in own row horn slot; occupied slots rejected by legal moves. |
| `PlayCard` weather | Yes | Frost, Fog, Rain, and Skellige Storm move to shared weather. |
| `PlayCard` Clear Weather | Yes | Clears active weather to each controller discard and discards itself, including no-weather boards. |
| `PlayCard` Decoy | Yes | Replaces target in exact row position and returns target to acting hand. |
| `PlayCard` Scorch | No | Legal move exists, but execution rejects with `unsupported_command` until ability resolution. |
| `Pass` | Yes | Marks passed, hands off turn, or enters `round_end` when both passed. |
| `UseLeader` Clear Weather | Yes | Clears weather, sets `leaderUsed`, leaves leader in leader zone, and consumes turn. |
| Other `UseLeader` abilities | No | Rejected with `unsupported_command` without marking used or advancing turn. |

## Event Model Changes

Added `mulligan_chosen`, `phase_changed`, `leader_used`, `player_passed`, `weather_cleared`, and `ability_deferred`. `card_played` now may include a compact target zone. `card_moved.reason` now includes `mulligan_return`, `mulligan_draw`, `play_card`, `decoy_return`, `weather_cleared`, and `discard_after_effect`. `turn_set.reason` now includes `turn_handoff`.

## Ability Deferral Policy

This phase executes placement and immediate Clear Weather only. Spy, Medic, Muster, Tight Bond, Morale, Unit Horn, Scorch Close, Mardroeme, Berserker, Summon, Avenger, and Roach-style muster are deferred with `ability_deferred` when their source is placed. Special Scorch remains legal but non-executable and is rejected until Phase 6 can resolve destructive effects.
