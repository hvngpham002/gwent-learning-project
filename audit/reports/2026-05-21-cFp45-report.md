## Deviations

- The existing public failure-mining artifact does not contain per-play
  `AiDecisionTrace` guard evaluation data, so cFp45 could not definitively
  prove whether cFp43's guard never reached geometry or whether an exception
  applied. The decision note therefore records proxy classifications from
  aggregate public fields and recommends trace-level telemetry before any
  further overinvestment patch.

## Risks/Follow-ups

- **Without trace data, classification is probabilistic.** Future phases should consider adding per-play guard evaluation data to the failure-mining pipeline.
- **The cFp43 tradeoff (+5 losses) remains unresolved.** The guard reduced the signal by 49% but regressed benchmark strength.
- **The remaining 26 cases are still 96.2% loss-correlated.** If a future phase adds cumulative-spend tracking, it should be carefully benchmarked against acceptance gates (expanded W/L >= 302, losses <= 93, current losses <= 19).
- **Northern Realms and Nilfgaard v1 dominate the remaining signal** (21/26 cases). Any future rule should be monitored for disproportionate impact.

## Recommended Next Step

Pause `legal-heuristic-v1` heuristic tuning. The cFp43 guard addressed the most egregious overinvestment cases (51→26). The remaining 26 cases do not show a single clear fixable pattern that fits the cFp45 allowed patch shapes. The next meaningful improvement vector should be ratings/search (as recommended by cFp44), or a broader architectural redesign of the round-investment guard if heuristic tuning continues.
