## Behavior Changed

- Added `WeatherRowOverlayEffect`, `WeatherRowOverlayViewModel`, and `buildWeatherRowOverlayViewModel(...)` in `src/components/gwent/matchViewModel.ts`.
- The helper maps public Weather-zone cards to row presentation effects:
  - Frost / `neutral.biting-frost` / `Biting Frost` -> close rows.
  - Fog / `neutral.impenetrable-fog` / `Impenetrable Fog` -> ranged rows.
  - Rain / `neutral.torrential-rain` / `Torrential Rain` -> siege rows.
  - Skellige Storm / `neutral.skellige-storm` / `Skellige Storm` -> ranged and siege rows.
  - Clear Weather -> no row overlay.
- Added Skellige Storm to the match card weather tag fallback so it renders consistently as a weather special in the authentic UI.
- `AuthenticMatchScreen.tsx` now passes public `weatherRuntimeCards` into `BoardTable`, computes a per-row overlay view model, and renders a row overlay stack behind board-row contents.
- Rows now expose hidden-safe `data-weather-overlay` and child `data-weather-effect` attributes for browser smoke coverage. These attributes contain public effect names only, not card instance IDs.
- CSS adds generated overlay backgrounds under the existing authentic match namespace. The current runtime backgrounds use the SVG assets at shared `opacity: 0.8`. Row labels, scores, cards, target buttons, drag/drop surfaces, and right-click inspection remain above the overlay; active-weather row labels and scores remain light/white for contrast.

No engine rules, scoring, legal moves, command execution, Redux adapter behavior, AI policy, catalog data, deck builder, Card Studio, route defaults, or legacy UI behavior changed.

## Deviations From Spec

- No runtime animation loop was added. This stays within the spec's static/CSS-only allowance.
- The committed source concept sheet and original PNG row strips are included for provenance, even though the current runtime CSS references the four user-converted SVG row-strip assets.
- The focused browser smoke plays one weather card per run rather than exercising all four weather sources in one run. Unit coverage locks all four mappings; `ci:browser` keeps the product route healthy.

## Risks And Follow-ups

- The user-converted SVG strips are larger than the original PNG strips. They are acceptable for the opt-in authentic UI pass, but later asset optimization can compare minified SVGs, compressed PNGs, or a cleanup of unused fallback assets.
- Multiple weather effects stack, with Skellige Storm rendered as its own later layer, but no bespoke combined-weather art exists yet.
- The overlay uses responsive row-strip assets on top of a responsive row; future board layout changes may require crop or `background-position` adjustments.
- Touch dragging and full Decoy / row-horn browser choreography remain cEp12 follow-ups, unchanged by this phase.
