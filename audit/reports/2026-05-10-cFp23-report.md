## Deck Taxonomy Added

The taxonomy now exists in code at `src/game/benchmark/decks.ts` and in
docs at `docs/research/literature/ai/benchmark-deck-taxonomy.md`.

- `smoke`: tiny regression suites for harness and policy plumbing.
- `starter`: stable official starter decks for reproducible faction
  coverage, not optimized strength claims.
- `mechanics`: future constructed rule/faction stress decks; no
  descriptors added in cFp23.
- `competitive`: future reviewed strong deck lists; no descriptors added
  in cFp23.

## Hidden-Info Safety Notes

The new starter matrix uses the existing public artifact serializer. It
serializes only public `benchmark-match-v1` records, public
`benchmark-summary-v1` summaries, and the public manifest/report. It
does not expose raw `MatchState`, `cardsById`, command logs, full event
logs, hand arrays, deck arrays/order, observations, `ownHand`,
`opponentHand`, raw `seat_a:` / `seat_b:` runtime card instance ids, or
`unsafeDebugResults`.

The committed-artifact test parses all starter matrix files and scans
the combined strings for the required hazard tokens.

## Determinism Notes

`benchmark-starter-matrix-v1/latest` uses stable run id
`benchmark-starter-matrix-v1:latest`. JSON output is recursively
key-sorted by the cFp22 artifact serializer, and the JSONL ledger writes
one stable public record per line.

Two immediate `npm run benchmark:starter-matrix` runs produced matching
artifact hashes. The smoke artifact diff remained empty after
`npm run benchmark:smoke`.

## Deviations From Spec

- `/ai-lab` documentation notes that cFp23 adds headless starter matrix
  artifacts, but no browser UI metadata was changed because UI changes
  are out of scope.
- Review correction before commit: the initial 60-record implementation
  fixed `legal-heuristic-v0` to the left deck and `legal-first-v0` to
  the right deck in each unordered starter pairing. The final cFp23 suite
  intentionally doubles those matchups so both policies pilot both decks
  in every starter pair before mirror expansion. This avoids a policy vs.
  deck-order confound and yields 120 public records.

## Risks And Follow-Ups

- The starter matrix is broader than smoke but still not a strength
  rating. It uses starter decks and a weak deterministic comparator.
- `legal-heuristic-v0` won the current starter matrix run in this run;
  this should be treated as a comparator sanity signal, not broad AI
  strength evidence. The final matrix now balances deck-level counts:
  every official starter deck records 24 wins and 24 losses because each
  deck is piloted by both policies across its pairings.
- Mechanics stress decks, competitive/best-in-faction deck lists,
  Glicko, TrueSkill, approximate best response, search policies,
  `legal-heuristic-v1`, Python tooling, browser benchmark execution, AI
  Lab artifact loading, and product difficulty tiers remain deferred.
