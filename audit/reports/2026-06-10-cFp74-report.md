## Behavior Changed

cFp74 adds a benchmark-only bounded second-ply public-action scaffold over the
cFp72/cFp73 scalar surface. It executes representative second-ply public
actions only inside cloned sampled benchmark states for in-cap roots and writes
hidden-info-safe scalar artifacts.

No gameplay behavior, engine rules, legal moves, AI policy behavior, sampler
semantics, deck/catalog data, UI runtime behavior, rating formulas, benchmark
suite definitions, or existing cFp68-cFp73 artifacts changed.

## Repair 1

The initial robust run exposed `sampled_root_rebuild_deferred` failures because
eligible over-budget roots were skipped before public-transfer memory was
primed. Repair 1 updates the cFp74 root observer so every root with both a
cFp68 eligible record and a cFp72 branching record obtains sampler
public-transfer memory before the cFp74 in-cap check.

Over-budget eligible roots now update memory through the established
cFp70/cFp71/cFp72 materialization path, then return without becoming observed
cFp74 roots and without executing second-ply commands. Inherited sampler-skipped
roots that are not cFp68 eligible still do not update memory.

## Repair 2

The next robust run cleared the rebuild-deferred blocker but stopped on the
90 MB artifact-size guard: `second-ply-roots.jsonl` was 96,711,964 bytes.
Repair 2 compacts only the `second-ply-roots.jsonl` artifact projection.

The compact projection omits repeated run/cap constants already represented in
manifest/summary, omits the repeated per-row schema marker, and serializes the
second-ply count maps sparsely by removing zero-valued entries. In-memory
result objects and summary aggregation keep full count maps; benchmark behavior
and coverage are unchanged.
