## Execution Boundary

Benchmark execution, headless simulation, training, search, ratings, Python tooling, file export, and unsafe/debug benchmark output were not wired into the browser.

The AI Lab uses static UI metadata in `src/components/gwent/aiLabViewModel.ts` and does not import from `src/game/benchmark`.

- AI Lab visible data is limited to public suite IDs, policy IDs, deck preset names, status copy, and documentation paths.
- The view-model and browser smoke assert that AI Lab text does not include `cardsById`, `finalState`, `commandLog`, `ownHand`, `opponentHand`, `seat_a:`, `seat_b:`, `instanceId`, or `sourceId`.
- Product/authentic code keeps the cEp16 legacy boundary and does not import from `@/legacy/...`.

- Disabled controls intentionally do not persist intent or queue work.
- Larger benchmark matrices, Glicko/TrueSkill, robustness/search probes, `legal-heuristic-v1`, product difficulty tiers, and training remain future work.
