## Repair Summary

### Repair 1 (`7d26e25`)
Replaced hardcoded `visibleHandCount: 0`, `opponentHandCount: 0`, and `opponentDeckCount: 0` with values derived from the current root `MatchState`:
- `ownHandCount` = `state.seats[seatId].hand.length`
- `opponentHandCount` = `state.seats[opponentSeatId].hand.length`
- `opponentDeckCount` = `state.seats[opponentSeatId].deck.length`

### Repair 2 (`b8c3d3f`)
Built the `known_preset_decklist_prior` from the **opponent seat** (not the acting seat) for validating opponent hand/deck counts:
- Derived `opponentSeatId` from acting `seatId`
- Read `opponentSeat = seats[opponentSeatId]`
- Used `opponentSeat.deckPresetId` and `opponentSeat.faction` for the prior used to validate `opponentHandCount` / `opponentDeckCount`
- Kept acting `seatId`, `policyId`, `faction`, and `deckPresetId` in root metadata as acting-seat metadata
- Updated `buildSampledWorldValidation` to validate against prior's `mainDeckCardCount`

### Repair 3 (`f72e61c`)
Fixed `buildSampledWorldValidation` so deferred roots report zero sample counts since real hidden multisets are not implemented:
- `rootValidationStatus = "deferred"` when count checks pass
- `sampleCountRequested = sampleCount` (unchanged, e.g. 8)
- `sampleCountGenerated = 0` (was `sampleCountValid + sampleCountInvalid`, misleadingly claimed samples were generated)
- `sampleCountValid = 0` (was `sampleCount`, incorrectly claimed all samples validated)
- `sampleCountInvalid = 0` (unchanged when no mismatches)
- `invalidReasonCounts = {}` (unchanged when no mismatches)
- Invalid roots still report nonzero `sampleCountInvalid`, `sampleCountGenerated`, and reason counts when validation genuinely fails

## Behavior Changed

**No gameplay behavior changed.** cFp60 adds benchmark-only infrastructure:
- `known_preset_decklist_prior` constructs prior info for official starter deck contexts only, built from the opponent seat's deck preset.
- `buildSampledWorldValidation` validates observed counts against prior main deck size; marks roots `deferred` (no real sampled multisets implemented, reports zero sample counts) or `invalid` (count mismatches, reports nonzero invalid counts).
- `buildPublicActionAbstraction` + `collapsePublicActions` group legal moves by public shape without raw ids.
- `runSamplerReadinessProfile` runs benchmark with root observer for sampler-readiness artifacts.
- CLI script `run-benchmark-sampler-readiness-report.ts` generates artifacts to `sampler-readiness/cFp60/`.
- npm scripts `benchmark:sampler-readiness:v1-starter-matrix` and `benchmark:sampler-readiness:v1-robust` run the CLI.
