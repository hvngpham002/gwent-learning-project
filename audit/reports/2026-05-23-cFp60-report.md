## Repair Summary

**cFp60 repair** replaced hardcoded `visibleHandCount: 0`, `opponentHandCount: 0`, and `opponentDeckCount: 0` with values derived from the current root `MatchState`:
- `ownHandCount` = `state.seats[seatId].hand.length`
- `opponentHandCount` = `state.seats[opponentSeatId].hand.length`
- `opponentDeckCount` = `state.seats[opponentSeatId].deck.length`

Updated `buildSampledWorldValidation` to validate against the known preset prior's main deck card count. Validation checks:
- Negative opponent hand/deck counts
- Observed cards exceeding prior main deck total
- Opponent deck exceeding prior main deck
- Opponent hand exceeding prior main deck

Since real sampled hidden multisets are not implemented, roots with valid counts are marked `deferred` (not `valid`). Roots with impossible counts are marked `invalid`.

Added `mainDeckCardCount` and `sideDeckCardCount` to `SamplerReadinessPriorInfo` to separate validation-relevant count from total deck count. Validation uses `mainDeckCardCount` (what the opponent actually draws from), not `totalDeckCardCount` (which includes side deck).

Added regression tests proving:
- Root records report real opponent hand/deck counts (not all zeros)
- Impossible count/prior mismatches are detected
- Validation returns `deferred` for consistent counts, `invalid` for mismatches
