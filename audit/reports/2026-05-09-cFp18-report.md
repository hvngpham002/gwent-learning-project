## Annotation Batch

Read only PDF pp. 1-10, covering:

- ReBeL's motivation as an RL-plus-search framework for imperfect
  information games;
- the modified Rock-Paper-Scissors example showing why
  perfect-information state-value search is not sound;
- related work on AlphaZero-style RL-plus-search, DeepStack
  public-belief-state value search, and Pluribus blueprint-policy
  search;
- factored-observation-game notation, public/private observations,
  infostates, public states, and two-player zero-sum scope;
- the conversion from world states to public belief states;
- public-belief-state subgames, infostate values, and the
  supergradient framing;
- Algorithm 1's self-play loop for value and optional policy network
  training;
- CFR-D, CFR-AVG, fictitious-play variants, and depth-limited subgame
  search;
- safe test-time search when the opponent policy is unknown;
- TEH, HUNL, and Liar's Dice experiment setup and first-batch results;
- the conclusion, broader-impact cheating-risk note, and first-batch
  references.

The annotation file records `pages_read: "1-10"` and keeps these
