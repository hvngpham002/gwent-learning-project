## CI Workflow Added

- `.github/workflows/ci.yml` runs on pull requests and pushes to `dev` or `main`.
- Uses Node 22, `actions/setup-node` npm cache, `npm ci`, and `npm run ci`.
- Uploads `dist/` as an artifact on push.
- Uses branch-level concurrency to cancel older runs.

## Package Scripts Added

- `typecheck`: `tsc -b --pretty false`
- `check:forbidden-imports`: `node scripts/check-forbidden-imports.mjs`
- `check:project-state`: `node scripts/check-project-state-update.mjs`
- `check:worktree-clean`: `node scripts/check-worktree-clean.mjs`
- `ci`: lint, tests, build, forbidden import check, project-state check, and worktree cleanliness check

- `dev` as active integration branch;

- CI gates without automatic deployment.
