## Annotation Workflow Changes

`docs/research/literature/ai/ANNOTATION_WORKFLOW.md` now requires source
intake to check:

- `docs/research/bibliography/references.bib` exists;
- the target citekey exists in `references.bib` or a verified entry is
  added;
- the source package manifest exists;
- `source.pdf` exists when the manifest says
  `status: local-source-available`;
- if no PDF exists, the manifest uses a non-local status such as
  `url-only` and the annotation does not claim local PDF reading.
