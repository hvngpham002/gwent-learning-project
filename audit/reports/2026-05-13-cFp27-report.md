## Behavior Changed

1. **Mulligan policy**: `legal-heuristic-v1` now redraws low standalone no-ability units (strength ≤ 3, no spy/medic/tight_bond/agile/etc., not Muster caller) when no higher-confidence redraw class exists. This catches `neutral.roach` when no `muster_roach` caller is in hand, through a generic rule — not a hard-coded Roach branch.

2. **Mulligan diagnostics**: `explainLegalHeuristicV1Decision` now produces `mulliganAnalysis` on `AiDecisionTrace` during mulligan phase, including reason kind, confidence, and value bucket. Playing-phase traces set `mulliganAnalysis: null`.

3. **Refactoring**: Mulligan candidate ranking extracted from `chooseMulliganMove` into shared `rankMulliganCandidates` helper, consumed by both policy selection and diagnostics builder.

## Hidden-Info Safety Notes

1. `mulliganAnalysis` exposes only broad reason categories (`linked_payload`, `muster_duplicate`, `low_standalone_unit`, `keep_hand`).
2. No card names, source IDs, instance IDs, raw move IDs, `cardIds`, or `linkedSourceIds` appear in mulligan diagnostics.
3. Selected move label is redacted: `"keep hand"` or `"mulligan hidden card"`.
4. `low_standalone_unit` describes a broad quality class, not a unique card identity. It is allowed because many cards satisfy the class (any strength ≤ 3 no-ability unit), and it does not reveal which specific card was redrawn.
5. Product diagnostic export scan passes for mulligan traces. Forbidden token test confirms scan rejects `neutral.roach`, `Roach`, `cardIds`, `linkedSourceIds`, and raw `mulligan:seat_b:...` move IDs.

## Explicit Calls

1. **Roach-without-caller**: Handled by the generic `low_standalone_unit` rule (strength 2, no abilities, unit kind). No source-ID-specific logic was added for Roach. The test uses `neutral.roach` with no `muster_roach` caller and verifies it is redrawn through the low-standalone path.

2. **Benchmark win/loss counts**: Smoke changed from 6/6 to 5/7. Starter matrix changed from 88/32 to 89/31. These are within expected variance for mulligan behavior changes (different initial hands affect downstream decisions).

3. **Mulligan diagnostics reveal broad categories only**: `selectedReasonKind` is one of four broad categories. No card identity is leaked. The value bucket (`low`/`medium`/`high`) provides strategic context without revealing specific cards.

4. **Low-strength ability-bearing cards excluded**: Spy, Medic, Tight Bond, Morale Boost, Agile, Berserker, Mardroeme, Decoy, Scorch, weather/special, Commander's Horn, and Muster callers are all excluded from low-standalone redraw by explicit ability checks.

## Risks And Follow-Ups

1. The low-standalone threshold (strength ≤ 3) is conservative and may miss edge cases where higher-strength units with no ability are equally weak standalone. A future tuning pass can adjust based on ledger review.
2. `agile` units are excluded from redraw entirely. This preserves Scoia'tael/Skellige row-flexibility but may keep weak Agile units that would otherwise be redrawn. A faction-aware mulligan phase could refine this.
3. Benchmark win/loss counts shifted slightly, consistent with mulligan behavior change. No statistical analysis was performed — these are smoke/matrix benchmarks, not ratings.
