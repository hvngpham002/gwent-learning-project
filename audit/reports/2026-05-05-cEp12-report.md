## Behavior Changed

- Added `buildSelectedCardDragTargetViewModel(...)`, a pure presentation helper that derives drag-eligible move ids and drag-specific hints from the existing cEp11 selected-card spatial target view model.
- Added native pointer drag/drop for visible playable human hand cards in `AuthenticMatchScreen.tsx`. Drag start uses a small movement threshold, selects the dragged card if needed, closes context menus, and ignores right-click and touch dragging.
- Legal drops resolve only through existing target buttons carrying `data-drop-move-id`; the id must also be present in the selected-card drag target view model. Invalid drops cancel locally and dispatch nothing.
- Added presentation-only drop state, drag state, drag preview, and card-flight overlay for successful human hand-card plays. The engine command dispatch still happens immediately and is not gated by animation.
- Added reduced-motion CSS that avoids transform-heavy card-flight animation.
- Preserved cEp11 click/keyboard controls, right-click inspection, no-target fallback actions, hidden-info boundaries, AI policy, engine rules, legal moves, catalog data, route defaults, deck builder, Card Studio, and Redux adapter behavior.

No dependency was added.

## Deviations From Spec

- Touch dragging is deferred. Touch users keep the existing tap/click target model.
- Full Decoy bounce/replacement choreography is deferred. The legal `card_instance` drop target wiring is implemented through the shared target button attributes and drag move-id model, and pure tests cover card-target drag ids, but browser smoke directly exercises row and weather paths only.
- The weather drag browser smoke starts from the selected-card target path by selecting the weather card before dragging. The component still selects on drag threshold for unselected playable cards, and the row smoke covers drag-start selection from an unselected hand card.

## Risks And Follow-ups

- Add browser coverage for Decoy or another `card_instance` card drop once a deterministic fixture is cheap enough to keep stable.
- Add browser coverage for row-horn drag once a stable Commander's Horn fixture is introduced.
- Touch drag may need a separate design pass to avoid scroll traps and mobile board overflow.
- Broader match motion, prompt/revival choreography, and full Decoy bounce remain future Cluster E polish.
