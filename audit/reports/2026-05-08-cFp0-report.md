## Risks And Follow-Ups

- The Gwent AI literature sweep prompt has not been run. Until at
  least one paper is annotated, Cluster F specs cannot cite
  annotation files; any AI/ML implementation spec written before
  annotations exist must explicitly label its research claims as
  project hypotheses.
- The seed queue under
  `docs/research/literature/ai/results/2026-05-08/queue.md` names
  anchor candidate authors / papers, but these are unverified
  retrieval leads. Primary sources must be verified during
  annotation before they are cited in any spec.
- Source PDFs are intentionally local-only. A future contributor
  pulling this repository will not have the same local PDFs and
  will need to retrieve them independently or work from `url-only`
  / `secondary-lead-only` manifests until they do.
- `docs/PROJECT_STATE.md` contains long-form Cluster D / Cluster E
  status prose. cFp0 did not rewrite that prose; subsequent
  Cluster F phases that change runtime AI behavior should refresh
  the relevant Cluster D / Cluster E sections at that point, not
  preemptively in this documentation phase.
- The roadmap update is concise by design. Subsequent Cluster F
  phases should re-evaluate whether the `Stages` table is the
  right structure for tracking literature-foundation, evaluation,
  and training milestones, or whether a separate
  `docs/overhaul-plan/cluster-f-plan.md` is warranted.
