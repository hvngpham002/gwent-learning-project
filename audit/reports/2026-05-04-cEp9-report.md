## Behavior Changed

- Score-card leaders now render a compact status line with category and state. The surfaced states are `ready`, `used`, `passive active`, `setup resolved`, `cancelled this round`, `unavailable`, and `no target`; categories are `active`, `passive`, `setup`, and `unknown/custom`.
- Current-round `cancel_leader` suppression is shown from the public selector flag `leader.cancelledThisRound`, which is derived from engine state rather than event-log inference.
- The leader action panel keeps dispatching exact legal `UseLeader` moves. Single active leaders now get ability-specific trigger labels such as `clear weather`, `restore card`, `draw from opponent discard`, `discard and draw`, `look at hand`, and `cancel leader`; cEp8 weather-choice behavior and row hints are preserved.
- Disabled leader reasons now come from `buildLeaderStatusViewModel`. If an active leader otherwise could act but no legal leader move exists, the UI shows a generic `no target` reason instead of recomputing rule-specific target availability.
- Custom/unknown leader sources keep the `unknown/custom` category label, but remain legal-move-driven: if the engine emits an implemented leader move, the action is enabled.
- Prompt panels now use ability-specific presentation for `cancel_leader`, `restore_discard_to_hand`, `draw_opponent_discard`, owner-visible `discard_two_draw_one_from_deck`, owner-visible `look_three_cards`, and `medic_revive`.
- Prompt option labels are generated from legal `choose_prompt_option` moves only. Non-owner prompts return no option details, and fallback labels redact raw runtime IDs.

## Risks / Follow-Ups

- Browser coverage was added to existing weather-choice and look-three-card paths, not every prompt family. The broader prompt matrix remains a good candidate for a future deterministic browser seed suite.
- The status view model intentionally avoids explaining every engine target rule. This keeps rule ownership pure, but some `no target` cases may need richer copy in a later UI phase if product review finds the generic reason too terse.
- `legal-heuristic-v0` behavior is unchanged; it still does not strategically value proactive `cancel_leader` or other high-leverage leader timing.
