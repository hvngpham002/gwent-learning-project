## Behavior Changed

Added `npm run benchmark:long` as a local orchestration command for
longer benchmark runs. It launches a Python runner that executes existing
benchmark npm commands, displays `alive-progress` output when the optional
Python package is installed, falls back to plain progress otherwise, and
writes per-run logs plus `run.json` and `summary.md` under ignored
`.local/benchmark-runs/`.

Profiles added:

- `smoke`
- `v1-current`
- `v1-current-repeat`
- `all-current`

No AI policy behavior, engine rules, legal moves, UI behavior, benchmark
suite definitions, catalog data, or deck presets changed.

## Risks And Follow-Ups

- The progress bar advances by benchmark step, not by individual simulated
  match record. Record-level progress should wait until a later benchmark
  runner emits safe progress events.
- `alive-progress` is intentionally optional and not added to the Node
  dependency graph. Users can install it in their Python environment with
  `python3 -m pip install --user alive-progress`.
- H100/Slurm job submission remains deferred. This runner is compatible
  with Slurm shells but does not request cluster resources itself.
