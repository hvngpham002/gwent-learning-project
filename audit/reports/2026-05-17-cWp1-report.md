# cWp1 Report - H100 Compute Experiment Guide

## Summary

cWp1 integrates the user-provided `docs/compute/` material into this Gwent
repository as an operational guide for future agents that may use the lab
Slurm/H100 cluster. It clarifies that current TypeScript benchmark commands are
CPU/Node workloads, while H100 access is reserved for future GPU-specific
experiments such as neural evaluators, model inference, embeddings, search, or
self-play pilots.

## Behavior Changed

Documentation and workflow only. No engine rules, UI behavior, AI policy,
benchmark harness code, catalog data, deck data, tests, or runtime scripts were
changed.

Operational behavior clarified:

- current `npm run benchmark:*` commands should use local hardware, the RTX
  desktop, or CPU-only Slurm allocations;
- H100 jobs require an experiment card and a GPU-specific purpose;
- large caches and outputs should live in `/tmp` job scratch or `.local/`;
- only audited, hidden-info-safe public artifacts should be committed.
