## Side-Deck Validation Policy Implemented

A non-empty `sideDeck` is valid only when all of the following are true:

- every side-deck source ID exists in the catalog;
- every side-deck card is tagged `side_deck_only`;
- every side-deck card belongs to the deck faction (or is neutral);
- every side-deck entry is linked from at least one main-deck card via `linkedSourceIds`;
- every side-deck count exactly matches the derived linked requirement.

Error codes emitted:

- `unknown_side_deck_card`
- `invalid_side_deck_card`
- `wrong_faction_side_deck_card`
- `unlinked_side_deck_card`
- `side_deck_count_mismatch`
- `side_deck_only_main_deck` (preserved from cBp4.1)

Side-deck synchronization is automatic. `addCardToDeck`, `removeCardFromDeck`, `changeDeckFaction`, and `duplicateDeckPreset` all rebuild the side deck from the current main deck through `syncLinkedSideDeck`. The deck builder screen never asks the user to manually sync; the UI surfaces the linked replacements as read-only.

## Deviations From Spec

- The Skellige starter uses leader `skellige.king-bran` (placeholder `weather_half_penalty`); the deck-builder warning surfaces but the deck remains `playable` per spec. No alternative implemented Skellige leader exists today.
- A handful of starter-deck cards still expose `muster_roach`/planned-ability warnings (e.g. neutral `Geralt of Rivia`, `Cirilla Fiona Elen Riannon`); the spec permits warnings since no implemented neutral hero of equivalent strength is available.
- `findCatalogSourceForLocalDeck` continues to scan the entire `currentDeckPresets` list (now seven entries). Local decks named after the new official starters could match those starters when the user clicks `reset to catalog`. This is consistent with the existing behavior for the two current presets and is documented in the deck-builder doc.
- Review follow-up: `AuthenticDeckBuilderScreen` now passes the active source set into `removeCardFromDeck` and `duplicateDeckPreset` so linked-side-deck sync stays correct for merged catalog/custom source sets.

## Risks/Follow-Ups

- Superseded by the 2026-04-29 follow-up below: the promoted official leader image paths now resolve to committed public image assets. Leader fallback rendering remains relevant for future custom or missing-path records.
- Only `clear_weather` produces executable leader legal moves. Implementing other leader abilities (e.g. `play_fog`, `play_frost`, `play_rain`, `scorch_siege`, `scorch_range`, `play_any_weather`) is the natural next rules phase.
- Avenger remains planned. `neutral.cow` is intentionally excluded from every official starter until Avenger lands.
- `findCatalogSourceForLocalDeck` name-matching can produce surprising resets if a user names a local deck after an official starter; consider stricter `local-${presetId}` matching in a future deck-builder polish.
