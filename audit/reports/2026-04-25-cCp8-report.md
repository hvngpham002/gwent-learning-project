# Cluster C Phase 8 Report - Round Resolution and Game End

## Summary

Added the pure core `ResolveRoundEnd` transaction. The engine now settles only the explicit `round_end` phase, uses the Phase 7 scoring pipeline for winner determination, decrements gems from post-score results, sweeps the battlefield to controller discard piles, applies continuing-round faction passives, starts the next round, or ends the game from post-decrement gem state.

## Files Changed

- `src/game/core/types.ts`: adds `ResolveRoundEnd`, round history/idempotency state, `RoundResult`, movement reasons, and round/game/faction events.
- `src/game/core/setup.ts`: initializes `roundStarter`, `roundHistory`, and `lastResolvedRound`.
- `src/game/core/legalMoves.ts`: exposes `resolve_round_end` as a system legal move during valid `round_end`.
- `src/game/core/commands.ts`: implements round result calculation, gem loss, board cleanup, game-end detection, next-round start, and faction passives.
- `tests/game/coreRoundResolution.test.ts`: adds focused Phase 8 regression coverage.

## Behavior Implemented

- `Pass` remains a phase transition only; it does not score, decrement gems, sweep, or start a round.
- `ResolveRoundEnd` validates `round_end`, both passed flags, no pending prompt, optional `seatId`, and duplicate logical settlement.
- Round outcomes come from `calculateScores`; tied scores apply exactly-one-Nilfgaard draw-win, while both-Nilfgaard ties remain true draws.
- Gem loss is clamped at 0 and game end is derived only after decrement.
- Cleanup moves board units/placeholders, row horns, and weather to the current controller discard pile.
- Continuing rounds reset pass flags, increment `round`, clear prompts, set `currentTurn`/`roundStarter`, and emit `round_started`.
- Monsters keeps one eligible controlled non-Hero Unit only when the game continues.
- Northern Realms draws one deck card only on a continuing round win.
- Skellige returns up to two random eligible non-Hero Units from discard at the start of round 3 and defers returned on-play abilities.

## Policies Documented

| Policy | Implementation |
|---|---|
| True-draw next starter | If the game continues after a true draw, previous `roundStarter` starts again and `turn_set.reason` is `"draw_policy"`. |
| Both-Nilfgaard tie | Both abilities cancel by project policy; the round remains a true draw and both seats lose 1 gem. |
| Monsters keeper eligibility | Eligible cards must be `unit`, non-Hero by source kind, physically on the Monsters seat's own board, and controlled by that Monsters seat. Opponent-controlled Spies on the Monsters board are excluded. |
| Skellige Agile row placement | Returned multi-row/Agile Units use the first row in catalog row order: close, ranged, siege. A faction event records the deterministic policy when used. |
| Skellige returned on-play abilities | On-play abilities are not executed in Phase 8. Returned cards with such abilities emit `ability_deferred` with `skellige_return_on_play_pending`. |
