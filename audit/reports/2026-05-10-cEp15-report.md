## Behavior Changed

- `/` now renders the authentic pre-game setup screen.
- `/legacy` renders the legacy Redux UI.
- `/engine-diagnostic` renders the diagnostic engine shell.
- Canonical authentic paths now select existing authentic sub-surfaces: `/match`, `/deck-builder`, `/card-studio`, `/official-porting`, `/components`, and `/ui-harness`.
- Old query URLs still resolve as compatibility aliases, including `/?engine=1` and `/?engine=1&ui=authentic&view=...`.
- `VITE_ENGINE_UI=1` no longer makes `/` leave authentic pre-game. The old helper remains for compatibility callers, but `App.tsx` uses the new path-aware resolver.
- No engine rules, legal moves, scoring, AI policy, benchmark harness, catalog data, Card Studio schema, deck validation, official-porting staging data, or hidden-info boundary changed.

## Route Contract Before/After

Before cEp15:

- `/` -> legacy Redux UI.
- `/?engine=1` -> diagnostic engine shell.
- `/?engine=1&ui=authentic&view=...` -> authentic product surfaces.

After cEp15:

- `/` -> authentic pre-game setup.
- `/match` -> direct authentic match route at mulligan.
- `/deck-builder` -> authentic deck builder.
- `/card-studio` -> Card Studio.
- `/official-porting` -> Official Porting.
- `/components` -> component foundation.
- `/ui-harness` -> UI harness/gallery.
- `/engine-diagnostic` -> diagnostic engine shell.
- `/legacy` -> legacy Redux UI.
- `/ai-lab` -> reserved in docs only; not implemented.
