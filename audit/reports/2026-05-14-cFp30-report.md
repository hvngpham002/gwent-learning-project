## Behavior Changed

- `estimateImmediateTempo(...)` uses weather-adjusted effective strength for non-hero board-row placements
- Non-hero units placed on weathered rows use base strength `1` instead of printed strength
- Heroes remain weather-immune and keep printed strength regardless of weather
- Commander's Horn doubles weather-adjusted strength (so weathered horned row scores ~2, not ~20)
- Spy placement on opponent weathered rows uses weather-adjusted signed tempo
- `effectivePlacedStrengthForPolicy` horn lookup fixed: opponent-side targets use `opponentSeatId` for row lookup instead of always using `seatId`
- `AiDecisionTrace` includes `weatherPlacementAnalysis` for playing-phase decisions
- `scanWeatherPlacementAnalysis` enforces weather-placement-specific forbidden tokens via dedicated scanner
- Weather placement analysis preserves only row names, counts, and strength buckets
