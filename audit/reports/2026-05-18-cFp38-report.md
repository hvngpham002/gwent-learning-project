## Behavior Changed

1. **Scoring penalty**: When a non-hero unit with printed strength ≥ 6 is placed on the AI's own weathered row with effective strength ≤ 3, and a clearly better legal line exists (same card non-weathered option with +4 effective strength, or different card/leader with +5 tempo and score ≥ MIN_USEFUL_MOVE_SCORE), the move receives a penalty of `180 + lostStrength * 22`.

2. **Tactical exceptions preserved**: Spy/card-advantage, strong Medic (best revive bucket = "strong"), Muster/linked callers, match-winning plays, last-gem catch-up, and no-better-line cases bypass the penalty.

3. **Diagnostics**: `AiDecisionWeatherPlacementAnalysis` gains three hidden-info-safe boolean fields: `selectedMoveLowTempoWeatherRisk`, `betterNonWeatheredAlternativeAvailable`, `weatheredLowTempoPenaltyApplied`.

4. **Reason strings**: When the selected move is a weathered-row low-tempo placement that triggered the penalty but no better line exists, the reason is "weathered row penalty accepted — no better visible line".

## Repair 1

Date: 2026-05-18

### Fixes Applied

1. **Unit-kind guard**: Changed `isOwnWeatheredLowTempoUnitPlacement` from `card.kind !== "hero"` to `card.kind === "unit"`. The original guard was too broad — it could have matched special cards (which don't go on board rows anyway, but the guard should be precise).

2. **Weather analysis field semantics**: `betterNonWeatheredAlternativeAvailable` is now computed independently as `hasBetterLine`, not gated behind `!hasExemption`. The field represents whether a better line exists, regardless of whether the selected move is exempt from the penalty. This allows diagnostics to correctly show that a better line exists even when a tactical exception prevents the penalty.

3. **Reason strings**: Fixed inverted logic. When `weatheredLowTempoPenaltyApplied` is true, the reason now says `"weathered row penalty applied — still best visible line (score X)"` instead of the inverted `"no better visible line"`. When the penalty is not applied but there's no better line, it says `"weathered row penalty accepted — no better visible line (score X)"`.

4. **Strengthened tests**: Replaced weak identity-only tests with behavior-proving fixtures. Added v0 isolation test using a real cFp38 scenario (not just policy ID checks). Added spy exception test. Verified reason strings for no-better-line case.

### Benchmark Impact

No benchmark re-run required. The repair only tightens the unit-kind guard (special cards don't target board rows) and fixes diagnostic/reason-string logic. No real scoring behavior change for legal unit moves.

### Note on matchDiagnostics.ts

`matchDiagnostics.ts` was not changed in this repair. The original report incorrectly implied scanner code changes were part of cFp38.
