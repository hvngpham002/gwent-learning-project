## Summary

Created the cFp58 decision note over the current engine, simulation, benchmark,
export, diagnostics, failure-mining, and rating substrate. The note defines
future variant labels and safety classes:

- `random-rollout-probe-v0`: `safe`
- `determinized-pimc-probe-v0`: `risky_requires_sampler`
- `so-ismcts-probe-v0`: `risky_requires_sampler`
- `oracle-pimc-debug-v0`: `unsafe_oracle_debug`

The decision note concludes that current code is ready for a hidden-info-safe
root profiler, not for safe hidden-state sampling or search play.

## Recommended cFp59 Target

cFp59 should implement a hidden-info-safe search-readiness profiler, not a
search-playing policy.

The profiler should collect root-state branching and budget metrics from
existing headless benchmark runs, write deterministic public artifacts under the
benchmark-results tree, include no rollouts/search/oracle mode, and produce the
distributions needed to decide whether a later `determinized-pimc-probe-v0` or
`so-ismcts-probe-v0` is the safer build target.

## Risks / Follow-Ups

- Safe sampling is not implemented. cFp60-style sampler work needs a named
  decklist prior, sampled-world validator, and public action abstraction.
- Future oracle/debug search must stay under an explicitly unsafe variant and
  artifact path.
- cFp59 should stop before search if root branching, prompt roots, or runtime
  profiling costs exceed local small-compute targets.
